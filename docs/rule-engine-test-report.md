## 四、新增/重点验证规则

- **SPEC-01 特殊人群剂量换算**：老人（≥65）足量氨氯地平→warn；儿童（≤14）未填体重→warn；成人常规剂量→不触发。
- **SPEC-02 禁忌症识别**：孕妇用卡托普利（孕妇禁用）→error；青光眼用硝酸甘油（青光眼禁用）→error；非孕妇用 ACEI→不触发。
- **INTER-01 深度相互作用**：华法林+阿司匹林→error；辛伐他汀+克拉霉素→error；ACEI+螺内酯→error。
- **FMT-01-EXT 分级扣分**：5种不出现；6种→warn；7种及以上→error。
