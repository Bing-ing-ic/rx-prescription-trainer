# 医学生处方推演训练平台 · UI/UX 测试报告

**测试日期：** 2026-11-04  
**测试环境：** Chrome 桌面端 1207×883px  
**测试版本：** v20261104r  
**测试范围：** 视觉设计一致性、响应式适配、交互流畅度、信息架构、可访问性、打印样式

---

## 一、整体设计评价

本平台作为医疗教育类产品，整体视觉风格**专业、克制、有医疗感**。以医疗深蓝（#0f4c81）为主色调，配合渐变蓝色 Hero 区域、心形医学图标和卡通护士形象，成功营造了"严肃教学 + 友好引导"的双重氛围。

报告页采用深色科技感设计（#0a1628 → #0f4c81 渐变），评分光环带发光效果，维度卡片带左侧色条，视觉层次分明，有较好的"成绩单"仪式感。

处方笺采用白底 + 细表格 + 黑色边框的仿真实样式，四种底色（普通/急诊/儿科/麻精）符合临床规范，打印样式完善。

**总体评分：7.8 / 10** — 完成度较高，具备医疗产品的专业感，但在细节统一、移动端适配和交互反馈上仍有提升空间。

## 三、详细问题列表

### 🔴 高严重度

#### P1. 处方笺表格在移动端可能横向溢出
- **位置：** `#view-rx` 处方笺页面，`.rx-table`
- **问题描述：** 处方表格有 9 列（#、通用名、规格、数量、单次剂量、途径、频次、疗程、操作），在 375px 手机宽度下几乎必然出现横向滚动。CSS 中 768px 断点仅将字号改为 12px、padding 缩小到 4px 6px，但没有处理列数过多的问题。
- **影响：** 手机用户无法完整查看处方表格，体验断裂。
- **改进建议：**
  - 移动端将表格改为卡片式布局（每味药一张卡片，字段纵向排列）
  - 或隐藏低优先级列（如"#"列、"操作"列），通过点击展开详情
  - 参考真实移动医疗 App 的处方展示方式

#### P2. 顶部导航按钮在小屏拥挤
- **位置：** `.topbar` → `.nav-btn`
- **问题描述：** 顶部有 5 个导航按钮（首页/药品库/能力画像/错题本/学习统计），加上左侧品牌文字，在 375px 宽度下必然换行或溢出。CSS 中 768px 断点仅将按钮 padding 改为 6px 10px、字号 12px，未解决数量过多的问题。
- **影响：** 移动端导航不可用，用户无法切换页面。
- **改进建议：**
  - 移动端折叠为汉堡菜单
  - 或将次要导航（能力画像/错题本/学习统计）放入底部 Tab 栏
  - 首页主导航只保留"首页/药品库"两个核心入口

#### P3. 触控目标尺寸不达标
- **位置：** `.nav-btn`、`.btn-xs`、`.chip`、`.tag`
- **问题描述：**
  - `.nav-btn` padding 仅 6px 14px，高度约 28px，远小于 Apple HIG / Material Design 推荐的 44×44px 最小触控目标
  - `.btn-xs` padding 2px 8px，高度约 22px
  - 处方表格内的 input 高度约 28px
- **影响：** 手机用户容易误触，点击精度差。
- **改进建议：** 移动端所有可点击元素最小高度 ≥ 44px，按钮 padding 增大到 12px 20px。

### 🟡 中严重度

#### P4. 圆角体系不统一
- **位置：** 全站
- **问题描述：** 项目中同时存在多种圆角值：
  - 按钮：6px（.nav-btn）、8px（.btn）、10px（.btn-type）、50px（.hero-btn）
  - 卡片：12px（.case-card）、10px（.iv-group）、16px（.hero-modern）、20px（.report-hero）
  - 标签：12px（.tag）、16px（.difficulty-row label）、20px（.hit-badge）
- **影响：** 视觉上不够精致，缺乏设计系统的秩序感。
- **改进建议：** 建立统一圆角规范，例如：
  - 小元素（标签/按钮）：8px
  - 卡片：12px
  - 大容器（Hero/弹窗）：16px
  - 胶囊形按钮/标签：999px

#### P5. 阴影风格不统一
- **位置：** 全站
- **问题描述：** 存在多种阴影风格：
  - `0 1px 3px rgba(0,0,0,.04)`（topbar）
  - `0 2px 12px rgba(15,76,129,.06)`（case-card）
  - `0 4px 20px rgba(15,76,129,.08)`（hit-section）
  - `0 8px 32px rgba(15,76,129,.2)`（hero-modern）
  - `0 8px 32px rgba(15,76,129,.3)`（report-hero）
- **影响：** 阴影颜色、模糊半径、透明度随意，缺乏层级体系。
- **改进建议：** 定义 3-4 级阴影 token：
  - shadow-sm: `0 1px 2px rgba(15,76,129,.05)`
  - shadow-md: `0 4px 12px rgba(15,76,129,.08)`
  - shadow-lg: `0 8px 24px rgba(15,76,129,.12)`
  - shadow-glow: 用于报告页发光效果

#### P6. 页面切换无过渡动画
- **位置：** 所有 `.view` 切换
- **问题描述：** 页面切换通过 `display: none / block` 直接切换，没有淡入/滑动过渡，感觉生硬突兀。
- **影响：** 交互流畅度下降，用户可能困惑"页面去哪了"。
- **改进建议：** 添加 200-300ms 的淡入动画：
  ```css
  .view { animation: fadeIn .25s ease; }
  @keyframes fadeIn { from { opacity: 0; transform: translateY(8px); } to { opacity: 1; transform: none; } }
  ```

#### P7. 缺少加载状态反馈
- **位置：** 提交点评、药品搜索、页面切换
- **问题描述：**
  - 点击"提交点评"后无 loading 状态，用户可能重复点击
  - 药品搜索输入后无"搜索中"反馈（虽然数据是本地 JSON，加载快，但首次加载 249KB drugs.json 时可能有延迟）
- **影响：** 用户不确定操作是否生效，可能重复提交。
- **改进建议：**
  - 提交按钮点击后变为 loading 状态（禁用 + 旋转图标）
  - 药品搜索添加 100ms 防抖和 loading 指示

#### P8. 基础字号偏小
- **位置：** `body` font-size: 14px
- **问题描述：** 正文 14px 在桌面端尚可，但在高分辨率屏幕和移动端偏小。医疗场景下用户可能需要仔细阅读病例和处方，字号过小会增加阅读负担。
- **影响：** 可读性下降，尤其对中老年教师或学生群体。
- **改进建议：**
  - 正文提升到 15-16px
  - 处方表格内文字保持 13px 即可（打印场景）
  - 移动端最小字号 14px

#### P9. 缺少 ARIA 标签和语义化
- **位置：** 全站按钮、输入框、导航
- **问题描述：**
  - 图标按钮（如"🖨 打印 / 存PDF"）没有 aria-label
  - 导航按钮没有 `aria-current` 指示当前页面
  - 处方表格的输入框没有关联 label
  - 弹窗没有 `role="dialog"` 和 `aria-modal`
- **影响：** 屏幕阅读器用户无法使用，可访问性不达标。
- **改进建议：** 逐步添加 ARIA 属性，优先处理表单和弹窗。

#### P10. 报告页护士形象在小屏挤压
- **位置：** `.report-hero` → `.patient-avatar`
- **问题描述：** 报告页 Hero 区域包含评分环 + 标题 + 护士形象 + 生命体征，横向排列。在 768px 以下时，CSS 仅将 `.nurse-img-wrap` 缩小到 80×100px、vitals 字号改为 10px，但整体横向布局在小屏仍然拥挤。
- **影响：** 报告页在平板/手机上布局混乱。
- **改进建议：** 移动端报告 Hero 改为纵向布局，护士形象移到右侧或底部。

### 🟢 低严重度

#### P11. 品牌文字过长
- **位置：** `.brand` → "××医科大学附属训练医院 · 处方推演训练平台"
- **问题描述：** 顶部品牌文字较长，在中等屏幕（900-1100px）时会挤压导航按钮空间。
- **改进建议：** 缩短为"处方推演训练平台"或使用缩写图标 + 短标题。

#### P12. Hero 区域心电图装饰线位置略低
- **位置：** `.hero-ecg`
- **问题描述：** 心电图波形在 Hero 底部 60px 区域，透明度 0.6，在某些分辨率下可能与护士形象重叠。
- **改进建议：** 调整 z-index 或位置，确保装饰元素不干扰主体内容。

#### P13. 错题本空状态设计简单
- **位置：** `#view-mistakes`
- **问题描述：** 空状态仅一行文字"暂无错题，继续保持！🎉"，缺少引导插画或下一步行动建议。
- **改进建议：** 添加一个卡通医生/护士插画，配文"去做一次训练吧"并加按钮链接到处方推演。

#### P14. 学习统计空状态无引导
- **位置：** `#view-stats`
- **问题描述：** 无数据时显示"暂无数据"，用户不知道该做什么。
- **改进建议：** 添加 CTA 按钮"开始第一次训练"。

#### P15. 药品库搜索框内边距和按钮样式不一致
- **位置：** `#view-drugs` 搜索栏
- **问题描述：** 药品库搜索框使用了内联样式（`style="flex:1;min-width:250px;padding:10px 14px;..."`），与全局 `.diag-row input` 的样式不统一（padding 11px 14px vs 10px 14px）。
- **改进建议：** 统一为全局输入框样式，移除内联样式。

#### P16. 难度筛选单选按钮样式可优化
- **位置：** `.difficulty-row label`
- **问题描述：** 难度筛选用自定义胶囊按钮包裹原生 radio，视觉效果不错，但选中态仅靠背景色变化，没有图标或对勾反馈。
- **改进建议：** 选中态添加 ✓ 图标或加粗文字，增强状态感知。

#### P17. 处方笺"处方编号"位置可能偏移
- **位置：** `.rx-no` position: absolute; right: 36px; top: 50px
- **问题描述：** 使用绝对定位，在医院名称字号变化或容器 padding 变化时可能错位。
- **改进建议：** 改为 flex 布局，与 `.rx-head` 自然排列。

### 移动端存在的问题

| 顶部 5 个导航按钮拥挤 | 高 | 无汉堡菜单折叠 |

## 五、处方笺样式专项验证

### 四种底色验证 ✅

| 类型 | CSS 类名 | 底色值 | 打印保留 | 临床规范 |
|---|---|---|---|---|
| 普通处方 | 默认（白底） | #fff | ✅ | 普通门诊白色 |
| 急诊处方 | `.emergency` | #fffbeb（淡黄） | ✅ | 急诊淡黄色 |
| 儿科处方 | `.pediatric` | #f0fdf4（淡绿） | ✅ | 儿科淡绿色 |
| 麻精处方 | `.narcotic` | #fef2f2（淡红） | ✅ | 麻精淡红色 |

**评价：** 四种底色符合《处方管理办法》的颜色编码要求，打印样式中也正确保留了颜色（`@media print` 中显式设置了各类型背景色 `!important`）。

### 打印样式验证 ✅

- ✅ 隐藏了所有交互元素（topbar、btn、picker、nav、footer）
- ✅ 处方笺边框改为黑色实线（`border: 1px solid #000`）
- ✅ 表格边框黑色，表头背景变白
- ✅ 输入框边框隐藏，只显示内容
- ✅ 医院名称字号放大到 22pt，字距 6px
- ✅ 处方笺四种底色在打印中保留
- ✅ 角落标签（如"普通"）在打印中隐藏

**小问题：**
- `.rx-corner` 在打印中隐藏，但这个标签本身是给用户看的类型标识，打印时处方笺底色已经能区分类型，所以隐藏是合理的。
- 缺少 `@page` 设置，建议添加 `@page { size: A4; margin: 15mm; }` 确保打印纸张正确。
