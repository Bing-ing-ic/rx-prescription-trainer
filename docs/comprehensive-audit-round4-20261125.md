# 第四轮全站评估与修复方案（MVP 工程 + 现代医学循证 + UI/UX 三视角）

> 评估时间：2026-11-25　基线：本地 = 远端 main = 线上（西药 798 / 饮片 509 / 用方 51 / 中成药 73 / 名方 113 / 规则 99 / 中医病例 26）
> 基线校验：`node scripts/validate-all.js` 39 项通过 / 0 失败；引擎冒烟命中 8 条规则正常；浏览器重载后控制台无未捕获 JS 异常。

## 一、评估覆盖与方法

- **数据层静态体检**：自定义诊断脚本对 drugs / herbs / formulas / patents / rules / tcm-cases 做 schema、重复名、别名类型、价格类型、剂量字段完整性扫描。
- **浏览器端走查**：本地 HTTP 服务实测首页、现代医学（病例→诊断→处方笺→检索）、药品库、速查（跨模块）、能力画像、错题本、学习统计、汉方学（辨证）、针灸学、解剖学共 10 个视图与四模块切换。
- **工程核对**：index.html 引用的 13 个压缩 JS + 1 个 CSS 全部落盘存在；响应式断点（768/640/480）、打印样式、`prefers-reduced-motion` 齐备；loading 遮罩由 `.show` class 控制，visibility 兜底。

## 三、主动补充（用户未明确提及、评估中发现的隐患）

- **S1 检索别名兜底**：与 E1 合并落地；补检索后商品别名/曾用名可被处方笺与药品库双向命中。
- **S2 校验脚本防回归**：把本轮确认的 schema 规则固化进 `validate-all.js`——`aliases` 必须为数组（或空数组）、溶媒标记一致性抽查、`price_yuan` 类型为数字或 null、性别专病 code 表与性别锁定逻辑对应。
- **S3 病例身份-年龄一致性**：在数据体检中增加"身份限定词（高中生/幼儿园/哺乳/老年/婴幼儿）与随机年龄段匹配"的扫描规则，避免再出现文案与随机年龄/性别矛盾。
- **S4 价格展示口径统一**：全库价格展示与费用统计统一走同一兜底函数，杜绝 ¥0.0 误导。

## 四、本轮落地范围（P1 全量 + S2/S4 工程加固）

1. drugs.json：E2 溶媒标记 ×2、E3 aliases 数组 ×4。
2. diseases.json：E6 MP-J15 两条文案去学龄身份。
3. app.js：E1 双检索接入别名、E4 价格兜底展示、E5 性别专病锁定、S4 价格口径统一。
4. validate-all.js：S2 增补数据一致性校验项。
5. 回归：`validate-all.js` → 改动 JS 则 `minify-all.js` 重压缩 → 版本戳 bump → 提交推送 main → 线上核验计数与命中。

## 五、验收标准

- 校验脚本新增项全部通过，无新增失败。
- 处方笺/药品库输入"内舒拿""伯克纳""金嗓子""麻黄素"均可命中对应药品。
- 随机抽测乳腺癌/乳腺炎病例性别恒为女，前列腺增生/睾丸扭转恒为男。
- price=null 品种在列表与详情不出现 ¥0.0，显示"暂无报价"。
- MP-J15 不再出现"高中生/学校"字样。
- 四模块可正常打开，控制台无未捕获异常。
