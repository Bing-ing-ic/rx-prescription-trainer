## 二、发现并修复的 Bug

### Bug 1（严重）：错题本永远存不进数据
- **现象**：提交有错误的处方后，错题本始终为空。
- **根因**：`Reviewer.score(hits)` 返回 `{total, dims, totalHits, errorCount, warnCount}`，**不含 `hits` 数组**；而 `saveMistakes(review, ctx)` 首行是 `if (!review || !review.hits) return;`，条件恒为真，直接返回。
- **复现**：任意开一张有错误的处方提交 → `localStorage['rx-mistakes']` 为空。
- **修复**：`submitRx` 改为 `saveMistakes(review, hits, ctx)`；函数签名改为 `saveMistakes(review, hits, ctx)`，从传入的 `hits` 取 error/warn。
- **验证**：CDP 实测提交后 `rx-mistakes` 长度=1，错题本页渲染出 1 张错误卡片。

### Bug 2（严重）：报告页生命体征是"编"出来的，不是病例真实值
- **现象**：心率/体温/血压随错误数上下浮动（错误越多体温越高），与本病例实际病情无关。
- **根因**：`renderReport` 用 `75 + errCount*4` 之类公式伪造，未使用疾病 `symptom_pool.vitals`。
- **修复**：生成病例时从疾病生命体征区间（如肺炎 `temp 38.5-39.2`、高血压 `bp` 偏高）抽取真实值存入 `patient.vitals`；报告面板直接显示该值。
- **验证**：糖尿病老人显示 HR 78 / T 36.5℃ / BP 130/80；harness 抽测肺炎→38.8℃/107次分，脱水儿→心率128，均与病情吻合。

### Bug 3（中）：儿科病例开出成人年龄
- **现象**：`URI-J00-PED 小儿急性上呼吸道感染`、`DIADEM-A09-PED 小儿腹泻病` 这类明确儿科病例，患者年龄却是 18-65 岁成人。
- **根因**：`newCase()` 的年龄逻辑只认写死的 `childOkDiseases` code 列表，不识别 `-PED` 后缀或"小儿"病名。
- **修复**：code 以 `-PED` 结尾或病名以"小儿"开头 → 直接生成 3-11 岁；老年病年龄段收紧为 60-80 岁。
- **验证**：PED 病例年龄实测落在 3-11 岁。

### Bug 4（中）：参考处方对比 diff-box 信息单薄、无缺/多判断
- **现象**：仅两行文字"参考方案…/你开了…"，看不出缺了什么、多了什么。
- **修复**：重写为集合比对——✅ 已覆盖首选药 / ❌ 缺少指南首选药 / ⚠️ 额外非首选用药（输液通道提示可改口服序贯），并保留教学要点。
- **验证**：糖尿病病例实测正确显示"缺少盐酸二甲双胍缓释片、额外多开苯磺酸氨氯地平"。

### Bug 5（中）：知识点卡片 tips-box 近乎空壳
- **现象**：只收 `IV-` 开头规则标题，多数处方显示"无特别知识点"。
- **修复**：新增 `KNOWLEDGE_TIPS` 映射表，按 rule_id 返回标题+正文（覆盖 POP-01 儿童喹诺酮、ABX-01/02 抗菌分级、IV-05 输液负面清单、IV-07 中药注射剂、DOSE-01 体重算剂量、FMT-01 五种药限制等 20 条）；无错误时给出"本次规范"正向卡片。
- **验证**：实测渲染 3 张知识点卡片。

### Bug 6（轻）：评分可能超过 100 分
- **现象**：合格处方得分出现 105 分（评分器各维度权重合计为 105，非 100）。
- **说明**：根因在 `js/review.js` 权重表，**按要求未改该文件**；前端在 `renderReport` 对展示分做百分制封顶（0-100），圆环/评级/数字显示一致。**请评分器工程师后续核对 DIMS 权重合计。**

### Bug 7（轻）：疾病类型分布只统计错题
- **现象**：统计页"疾病类型分布"只数错题，全对的病例不参与分布。
- **修复**：`saveHistory` 增加记录疾病名/编码；分布改为基于全部训练历史（错题数据作兜底）。

## 三、新增 / 专业化增强

### a) 患者画像真实性
- 年龄与疾病强匹配：儿科病例 3-11 岁、老年慢病 60-80 岁、普通成人 18-65 岁。
- 生命体征按疾病区间抽取真实值：肺炎发热心动过速、高血压血压偏高、脱水心率快、儿童血压偏低。
- 费别与人群匹配：儿童多为城乡居民医保、老年慢病多为城镇职工医保。

### b) 处方打印模板（@media print）
- 保留处方笺颜色编码到打印输出：普通白色 / 急诊淡黄 / 儿科淡绿 / 麻精淡红（符合《处方管理办法》处方笺样式）。
- 原打印 CSS 会把儿科淡绿强制打成纯白，已修正；`no-print` 元素、工具栏、picker、提醒条均隐藏，处方编号格式 `MZ-JCK-YYYYMMDD-XXXXXX`。

### c) 知识点卡片
- 20 条 rule_id → 医学知识点映射，点评页自动按本次命中规则生成卡片，例如命中"儿童禁用喹诺酮"即展示喹诺酮对软骨发育影响的原理。
