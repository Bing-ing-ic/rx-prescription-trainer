## 一、模块概述

中医汉方模块围绕"辨证→立法→选方→用药"的中医临床思维链展开，包含**中药饮片库、经典方剂库、病例库、规则引擎**四大组件。

**总体印象**：

- 中药库覆盖了解表、清热、泻下、祛风湿、化湿、利水、温里、理气、理血、化痰、补虚、收涩、平肝等14大类，约300味常用药，性味归经、用量、功效主治总体符合《药典》与教材规范，**完成度约85%**。
- 方剂库40首方以《伤寒论》《金匮要略》《太平惠民和剂局方》《温病条辨》为核心，覆盖解表、泻下、和解、清热、温里、补益、理气、理血、祛湿、祛痰、消食、安神、平肝等主要门类，**方源选择得当**。
- 病例库26例涵盖感冒、咳嗽、胃痛、便秘、不寐、头痛、眩晕、消渴、痹证、泄泻十大常见病种，难度分初/中/高三级，**贴近中医内科教学大纲**。
- 规则引擎内置十八反、十九畏、剂量阈值、君臣佐使结构检查，外部JSON补充31条规则，**设计思路正确，但实现层面存在若干医学与代码问题**。

**综合评分（医学教学维度）**：**78 / 100**。作为中医本科生临床思维训练工具已基本可用，但存在若干必须修正的医学错误（尤其是朱砂用量、君臣佐使标注、十八反代码bug），否则会误导学生。

### 3.2 方剂库问题清单

#### 🔴 问题 F-01：朱砂安神丸朱砂用量严重错误（P0）
- **位置**：`tcm-formulas.json` ZSAST 朱砂安神丸 line 500
- **现状**：`{"herb": "朱砂", "role": "君", "dose": "3g"}`
- **医学错误**：
  1. 朱砂《药典》用量为 **0.1-0.5g，只入丸散，不入煎剂**。方中写3g，超药典上限6倍。
  2. 朱砂安神丸（《医学发明》）原方朱砂为**灯草汤下小丸**，朱砂剂量按丸剂配比，绝非汤剂3g。
  3. 病例 TCM-013 reference_herbs 同样列入"朱砂"，但未标剂量、未标"入丸散"。
- **正确应为**：朱砂 0.1-0.5g（研末冲兑现服，不入煎剂），或直接改为朱砂安神丸成药（每次1-2丸，日2次）。
- **教学风险**：学生若照此开方，可致汞中毒。
- **严重度**：🔴 **P0 必须修正**

#### 🔴 问题 F-02：理中丸君药标注错误（P0）
- **位置**：`tcm-formulas.json` LZW 理中丸 line 302-305
- **现状**：
  - 人参 9g role 君
  - 干姜 9g role 臣
  - 白术 9g role 佐
  - 炙甘草 6g role 使
- **医学错误**：理中丸（汤）出自《伤寒论》，功用"温中祛寒，补气健脾"，针对**脾胃虚寒证**。方中**干姜为君**（温中祛寒），人参为臣（补气健脾），白术为佐（健脾燥湿），甘草为使（调和诸药）。
- **教材依据**：新世纪《方剂学》："干姜大辛大热，温脾阳，祛寒邪，为君药。"
- **正确应为**：干姜 君、人参 臣、白术 佐、炙甘草 使。
- **教学风险**：学生误以为理中丸君药是人参（补气为主），偏离"温中祛寒"的立方本意。
- **严重度**：🔴 **P0 必须修正**

#### 🟡 问题 F-03：大承气汤君臣佐使标注偏差（P1）
- **位置**：`tcm-formulas.json` DCQT line 121-124
- **现状**：
  - 大黄 12g 君
  - 厚朴 15g 臣
  - 枳实 12g 臣
  - 芒硝 9g 佐
- **医学偏差**：教材大承气汤：大黄苦寒泻热通便为君；**咸寒软坚润燥为臣（芒硝）**；厚朴、枳实行气散结、泻痞满为佐。平台将芒硝降为佐、厚朴枳实升为臣，与教材不符。
- **剂量偏差**：原方厚朴24g（炙），平台用15g，偏轻但现代临床可接受。
- **正确应为**：大黄 君、芒硝 臣、厚朴 佐、枳实 佐。
- **严重度**：🟡 **P1**

#### 🟡 问题 F-04：乌头汤制川乌用量超药典（P1）
- **位置**：`tcm-formulas.json` WUT 乌头汤 line 831
- **现状**：`{"herb": "制川乌", "role": "君", "dose": "6g"}`
- **医学问题**：《药典》制川乌用量为1.5-3g（先煎、久煎）。6g超药典上限一倍。《金匮》原方川乌五枚（约折算现代3-5g），现代临床制川乌常用3-9g先煎久煎，但作为教学平台应严守药典上限。
- **正确应为**：制川乌 3-6g（先煎30-60分钟），或标注"由医师根据病情调整，须先煎久煎"。
- **关联问题**：引擎 `DOSE_LIMITS.川乌 max:6g` 会放过6g，但规则 TCM-DOSE-01 写"川乌/草乌>3g判error"，二者自相矛盾。
- **严重度**：🟡 **P1**

#### 🟡 问题 F-05：薏苡仁汤中川乌未标"制"（P1）
- **位置**：`tcm-formulas.json` YYRS line 858
- **现状**：`{"herb": "川乌", "role": "佐", "dose": "3g"}`
- **医学问题**：生川乌毒性大，临床内服必须用**制川乌**（制草乌同）。方中写"川乌"易被学生理解为生川乌。病例 TCM-023 reference_herbs 同样写"川乌"。
- **正确应为**：统一改为"制川乌"。
- **严重度**：🟡 **P1**

#### 🟡 问题 F-06：药名不统一（P2）
- **现状**：
  - 桑菊饮写"杏仁"（line 74），麻黄汤写"苦杏仁"（line 13），麻子仁丸写"杏仁"（line 144）
  - 半夏厚朴汤写"苏叶"（line 544），其他方写"紫苏叶"
  - 乌头汤、麻子仁丸写"芍药"未标明赤芍/白芍
- **正确应为**：统一使用《药典》通用名"苦杏仁"；"苏叶"规范为"紫苏叶"；"芍药"应标明赤/白芍（乌头汤宜白芍，麻子仁丸宜白芍）。
- **严重度**：🟢 **P2**

#### 🟡 问题 F-07：消渴方含"乳汁"（P2）
- **位置**：`tcm-formulas.json` XKF line 773
- **现状**：方中含"乳汁 30ml"
- **医学问题**：古代方用新鲜人乳，现代临床已基本不用（伦理、传染病风险）。病例 TCM-019 reference_herbs 未列乳汁，合理。
- **建议**：保留原文以体现方源，但应在 `contraindications` 或 `note` 中标注"现代临床多去乳汁，以藕汁、蜂蜜代"。
- **严重度**：🟢 **P2**

#### 🟢 问题 F-08：止嗽散、天麻钩藤饮君药标注偏窄
- **现状**：止嗽散紫菀君、百部臣；天麻钩藤饮天麻君、钩藤臣。
- **教材依据**：止嗽散紫菀、百部**均为君**；天麻钩藤饮天麻、钩藤**均为君**。
- **严重度**：🟢 **P2**（不影响主症对应，但君臣佐使结构教学不严谨）

### 5.2 规则引擎问题清单

#### 🔴 问题 E-01：十八反药组代码bug（P0）
- **位置**：`tcm-engine.js` line 15
- **现状**：
  ```js
  { a: ['藜芦'], b: ['人参','红参','西洋参','党参','丹参','玄参','南沙参','北沙参苦参','细辛','赤芍','白芍'] }
  ```
- **bug**：`'北沙参苦参'` 是**一个字符串**，应为 `'北沙参'` 和 `'苦参'` 两个独立元素。
- **后果**：当处方中同时出现藜芦与苦参，或藜芦与北沙参时，引擎**无法识别**十八反配伍禁忌（因为数组里没有单独的"苦参"或"北沙参"元素）。
- **正确应为**：
  ```js
  { a: ['藜芦'], b: ['人参','红参','西洋参','党参','丹参','玄参','南沙参','北沙参','苦参','细辛','赤芍','白芍'] }
  ```
- **严重度**：🔴 **P0 代码bug**

#### 🔴 问题 E-02：模糊匹配导致"白附子"误判为"附子"（P0）
- **位置**：`tcm-engine.js` line 75 `matchAny` 函数
- **现状**：
  ```js
  function matchAny(names, target) {
    return names.some(n => target === n || target.indexOf(n) >= 0 || n.indexOf(target) >= 0);
  }
  ```
- **bug**：当药名列表中有"附子"，处方中有"白附子"时，`n.indexOf(target)` 即 `'白附子'.indexOf('附子') >= 0` 为 true，误判为处方含附子。
- **后果**：
  1. 白附子（禹白附，独角莲）实际**不反半夏、瓜蒌、贝母、白蔹、白及**（十八反中乌头类指川乌、草乌、附子，不包括白附子）。但引擎会误报"十八反：乌头反半夏"。
  2. 白附子用量3-6g，但引擎会按附子3-15g阈值检查，可能误报剂量错误。
- **正确应为**：药名匹配应先做**精确匹配**，再做规范化别名映射（建立别名表如"法半夏→半夏"），禁止裸 `indexOf` 双向包含。
- **严重度**：🔴 **P0 代码bug**

#### 🟡 问题 E-03：川乌剂量阈值自相矛盾（P1）
- **位置**：`tcm-engine.js` line 37 `DOSE_LIMITS.川乌 max:6g` vs `tcm-rules.json` TCM-DOSE-01 "川乌/草乌>3g判error"
- **现状**：引擎内置川乌上限6g，但外部规则JSON写>3g判error。实际运行时引擎只执行内置DOSE_LIMITS（6g），外部规则的3g阈值**未被引擎读取执行**。
- **后果**：学生开川乌4-6g不会被引擎报错，但外部规则声明应该报错。
- **正确应为**：统一为药典标准——川乌、草乌 **1.5-3g**（先煎久煎），超3g判error。制川乌同。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-04：外部JSON规则未真正执行（P1）
- **位置**：`tcm-engine.js` line 191-204
- **现状**：引擎加载 `tcm-rules.json` 后，只处理 `r.type === 'herb_pair'` 类型的规则，而 `tcm-rules.json` 中31条规则均使用 `trigger`/`group` 字段，**没有 `type: 'herb_pair'` 字段**。
- **后果**：外部JSON的31条规则（十八反十九畏、证候禁忌、君臣佐使完整、脚注、妊娠、小儿剂量等）**实际上都没有被引擎执行**。引擎只运行内置的少量检查。
- **严重度**：🟡 **P1 架构问题**——规则JSON形同虚设。

#### 🟡 问题 E-05：君臣佐使结构检查不完整（P1）
- **位置**：`tcm-engine.js` line 155-159
- **现状**：只检查"是否有君药"（hasJun），未检查臣、佐、使是否齐全。
- **外部规则 TCM-FMT-01** 要求"君、臣、佐、使缺失任一角色判error"，但引擎未实现。
- **正确应为**：检查方中是否同时存在 role 为君、臣、佐、使的药（部分方可合并如"佐使"），缺失则warn。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-06：未对照 tcm-herbs.json 的 dose_range 逐项检查（P1）
- **位置**：`tcm-engine.js` line 165-188
- **现状**：剂量检查只查内置 DOSE_LIMITS 12味药 + 通用>30g警告，未对其他药物对照 `tcm-herbs.json` 的 `dose_range` 字段逐项检查。
- **外部规则 TCM-FMT-03** 要求"对照 tcm-herbs.json dose_range 上下限，超出上限判error"，引擎未实现。
- **后果**：如学生开石膏100g（药典15-60g）、麻黄15g（药典2-10g），引擎不报错。
- **正确应为**：加载 tcm-herbs.json 后建药名→dose_range映射，逐药解析上下限并比对。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-07：妊娠禁忌、先煎后下、证候禁忌未实现（P1）
- **现状**：外部规则 TCM-INCOMPAT-03（妊娠禁忌）、TCM-USG-01~07（先煎后下包煎烊化另煎）、TCM-INCOMPAT-04/05（寒热虚实证候禁忌）在引擎中**均无对应实现代码**。
- **后果**：孕妇处方含附子、桃仁、红花不报错；含石膏、石决明未标先煎不警告；寒证用大队寒凉药不提示。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-08：TCM-FMT-05 示例文字错误（P1）
- **位置**：`tcm-rules.json` line 49
- **现状**：`"herb.name 使用别名俗名（如元参/乌元参/瓜蒌皮应写天花粉/瓜蒌）"`
- **医学错误**：**瓜蒌皮不等于天花粉**。瓜蒌皮是葫芦科植物栝楼的果皮，天花粉是其根，二者功效不同（瓜蒌皮清肺化痰、利气宽胸；天花粉清热生津、消肿排脓）。不能互相替代。
- **正确应为**：举例应改为"如处方写'元参'应规范为'玄参'；写'忍冬花'应规范为'金银花'"。删除"瓜蒌皮应写天花粉"这一错误类比。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-09：妊娠禁忌药列表自相矛盾（P1）
- **位置**：`tcm-rules.json` TCM-INCOMPAT-03 line 80、TCM-POP-01 line 310
- **现状**：
  - 禁用列表含"桃仁、红花、大黄、芒硝"
  - 慎用列表又含"红花"
- **医学错误**：《药典》2025版妊娠禁忌：
  - **禁用**（绝对）：巴豆、斑蝥、麝香、三棱、莪术、水蛭、虻虫、芫花、藜芦、川乌、草乌、附子、甘遂、大戟、牵牛子等
  - **慎用**（相对）：红花、桃仁、大黄、芒硝、牛膝、川芎、牡丹皮、枳实、肉桂、半夏等
- **正确应为**：桃仁、红花、大黄、芒硝应从"禁用"移至"慎用"；红花只列一次。
- **严重度**：🟡 **P1**

#### 🟡 问题 E-10：TCM-SYN-03 选方不符 severity 不一致（P2）
- **位置**：`tcm-rules.json` line 130 vs `tcm-engine.js` line 119
- **现状**：外部规则声明"选方差距过大判 error"，引擎实际实现为 warn（TCM-FM-01）。
- **建议**：统一为 warn（同类方不同方）+ error（完全不相关方）两级，与 TCM-EFF-03 匹配度评分联动。
- **严重度**：🟢 **P2**

#### 🟢 问题 E-11：TCM-EFF-02 君臣剂量比例规则过于机械（P2）
- **位置**：`tcm-rules.json` line 180
- **现状**："君药剂量应大于臣佐药；若君药剂量反小于佐使药判warn"。
- **医学讨论**：教材中多首方君药剂量并不绝对大于臣佐，如桂枝汤桂枝9g=白芍9g，小柴胡汤柴胡24g君远大于臣黄芩9g（此例合理），但补中益气汤黄芪18g君 vs 炙甘草9g臣（合理）。机械比较剂量绝对值会误报。
- **建议**：改为"君药应在方中起主导作用，若君药剂量<臣药1/3且无特殊配伍理由，判warn"。
- **严重度**：🟢 **P2**

## 六、教学价值评估

### 6.1 优点

1. **中医思维链完整**：辨证→立法→选方→用药四步训练，符合中医临床思维培养规律。
2. **难度分级合理**：初级（表证、单一证型）→中级（脏腑辨证、复合证型）→高级（痹证、消渴、复杂病例），梯度清晰。
3. **病种覆盖广**：26例覆盖中医内科10大常见病种，符合本科中医内科学教学大纲。
4. **鉴别诊断设计**：每例列3个鉴别诊断，训练学生鉴别思维。
5. **药物安全意识强**：十八反、十九畏、妊娠禁忌、峻烈药剂量、先煎后下等规则设计体现了临床安全用药思维。
6. **异病同治/同病异治**：TCM-016/017头痛与眩晕同用天麻钩藤饮，TCM-014/018不寐与眩晕同用归脾汤，体现中医辨证论治灵魂。

### 6.2 不足

1. **舌脉信息偏模式化**：所有病例舌脉描述简短，缺乏"舌脉不符"等临床复杂情况训练。
2. **缺少合方/加减训练**：reference_herbs 基本是原方组成，少量加减（如二陈汤加苏子白芥子），训练学生"方随证转、随证加减"的能力不足。
3. **缺少西医结合视角**：消渴病例虽提到血糖，但整体病例未体现中西医结合诊疗思路（如糖尿病肾病、高血压靶器官损害等）。
4. **缺少误诊/纠错案例**：病例均为典型证型，未设"学生易错选方"的陷阱题。
5. **中药库"功能主治"偏药典式**，未体现"配伍意义"（如麻黄汤中麻黄配桂枝、麻杏配甘草的配伍机理），教学深度可加强。

## 七、临床逻辑评估

### 7.1 优点

- 诊疗流程：主诉→病史→舌脉→检查→辨证→治法→选方→用药，与真实中医门诊一致。
- 安全规则覆盖：十八反十九畏（error级）、峻烈药剂量（error级）、妊娠禁忌（error级）体现了临床底线思维。
- 煎服法规则：先煎（矿物/有毒药）、后下（芳香药）、包煎（花粉/绒毛）、烊化（胶类）、另煎（贵重药），符合《中药药剂学》规范。
- 中病即止：解表剂、峻下剂疗程限制，体现中医"大毒治病十去其六"思想。

### 7.2 不足

1. **规则引擎与外部JSON脱节**（见 E-04）：31条规则实际未执行，临床逻辑闭环未真正建立。
2. **缺少"复诊/病情变化"场景**：真实中医是动态调整处方的，目前均为单次开方。
3. **缺少中西医鉴别诊断**：如胃痛病例未提示"须排除消化性溃疡、胆囊炎、心梗"等危急病，可能误导学生将所有上腹痛按胃病处理。
4. **检查舌脉与辨证的逻辑链**：规则 TCM-SYN-04 提到八纲自相矛盾，但引擎未实现"舌脉与辨证一致性"自动校验。
