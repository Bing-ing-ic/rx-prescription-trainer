## 2. 字段口径与枚举定义

### 2.1 drugs.json 新增字段
| 字段 | 取值 | 说明 |
|---|---|---|
| `origin_type` | `imported_originator` 进口/境外原研；`jv` 中外合资；`domestic` 国产（含仿制、国产中成药、中药注射剂）；`innovative` 新机制创新药；`unknown` 依据不足 | 判定优先级：新机制药（单抗/TKI/ADC/PD-1/PD-L1/PCSK9/GLP-1/SGLT2/JAK/IL 类/融合蛋白/siRNA/BCL-2/BTK/PARP/mTOR/IMiD 等）优先标 `innovative`；其余按厂家归属；厂家为空或多厂家/多文号混合串无法判定 → `unknown` |
| `drug_category` | `western` 化药；`patent_tcm` 中成药成药；`tcm_injection` 中药注射剂；`solvent` 溶媒 | 与既有 `is_solvent` / `is_tcm_injection` 字段一致性已校验 0 冲突 |
| `pharmacopoeia` | `"2025二部"` / `"2025三部"` / `""`（待核） | 仅在活性成分明确属经典药典品种时填；复方/肽类/新型生物药归属无把握一律留空，禁止臆造 |

### 2.2 tcm-herbs.json 新增字段
| 字段 | 取值 | 说明 |
|---|---|---|
| `processing` | 炮制规格：生品/蜜炙/制/煅/炒炭/酒炙/醋炙/盐炙/煨/鲜品等 | 名称已含炮制者据实填（炙甘草→蜜炙，制川乌→制，棕榈炭/血余炭→炒炭） |
| `usage_detail` | 煎服法细则：煎服/冲服/入丸散/先煎/后下/烊化/包煎/另煎/兑服等 | 既有 `usage` 内容并入后保留 `usage` 不删 |
| `pharmacopoeia` | `"一部"` / `""`（待核） | 常用药典饮片填 `"一部"`；保护动物禁用、人乳汁、现代基本不用、含氧化汞等非常规收载项留空 |

### 2.3 tcm-patent-drugs.json
- 保持字典（前端未接通，本轮不接 UI）；每条补 `pharmacopoeia: ""`（待核），不改既有字段、不强行对齐 drugs.json schema。

## 5. 存疑待核清单

1. **unknown 120 条**：厂家字段空 94 条；厂家非空但归属存疑/混合串 26 条（多厂家/受托生产/双文号串，如穿琥宁、银杏达莫、野木瓜、莪术油、丹红、舒血宁、香丹、红花、灯盏花素、血塞通、丹参川芎嗪等）；明细见打标代理复核清单。
2. **合资/独资边界**：上海强生、北京韩美（中韩合资背景）、华瑞制药（历史合资）、成都康弘、香港澳美、泰姆勒、康宝药业、欧盟制药、阿尔法公司等主体性质待工商/说明书核实，暂置 `unknown`。
3. **药典二部标引复核**：66 条二部标引按高置信经典成分配方匹配；其中复方制剂（阿莫西林克拉维酸钾片、甲硝唑氯化钠注射液、妥布霉素地塞米松滴眼液等）建议抽查 2025 版药典二部正文是否收载对应制剂品种。
4. **药典留空肽类/新型生物药**：胰岛素、胸腺法新、特立帕肽、鲑降钙素、英克西兰（siRNA）等，分部归属无把握，留空待核；中成药/中药注射剂一部收载状态未核，全部留空。
5. **保护动物/禁用条目**：熊胆、穿山甲、犀角为保护动物禁用条目，仅作历史/警示保留；羚羊角、雪莲花（天山雪莲）来源合规性待核；紫河车免疫传播风险与留存必要性待核。
6. **别名映射待统一**：字典名与药典正名存在别名关系（贯众→绵马贯众、刘寄奴→北刘寄奴、藿香→广藿香、龙胆草→龙胆、贝母→川贝母/浙贝母、白豆蔻→豆蔻、益智仁→益智、红藤→大血藤、夜交藤→首乌藤、代赭石→赭石、刺蒺藜→蒺藜、海蛤壳→蛤壳、苏子→紫苏子、杏仁→苦杏仁、苏叶→紫苏叶、大戟→京大戟、白芥子→芥子、罗布麻→罗布麻叶、莲子肉→莲子、白蜜→蜂蜜、当归尾→当归等），是否更名/补别名表下批统一。
7. **近重复条目**：赭石/代赭石字典内两条近重复，是否合并待核；`0.9%氯化钠注射液`×2、`10%葡萄糖注射液`×2 为入库前既有同名不同规格记录，本轮未删改。
8. **毒性药材口径**：轻粉（氯化亚汞）、红粉（氧化汞）、升药、砒石、砒霜、铅丹、密陀僧、胆矾等毒性矿物药，内服剂量与使用口径待药典/教材复核；千金子、急性子、鹤虱、山慈菇、重楼等有毒/妊娠禁忌候选已在候选池单列标注。
9. **黛蛤散**：药典一部按成方制剂收载（非饮片），`pharmacopoeia` 标 `"一部"` 口径待核定。
