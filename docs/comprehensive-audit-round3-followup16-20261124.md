# followup16 名方品鉴栏目 · 交付报告（2026-11-24）

## 一、概述与合规边界

在中医汉方模块下新增只读学习栏目「名方品鉴」，分两组：**中国历代典籍经典名方（40 首）** 与 **日本汉方经典药方（28 首）**，共 **68 首**。

合规边界（硬性落实）：

- 只收有明确典籍 / 文献出处的成方；无根民间验方、偏方、巫术方、祝由 / 术数类一律未收。
- 日本条目逐条标注源流归属（沿用《伤寒论》《金匮》原方 / 中方后世医籍成方 / 日本本土化裁）；中日剂量、适应证、剂型、药味差异在 `cn_jp_diff` 字段并列注明，不混为一谈。
- 古方度量衡折算注明口径；栏目全站标注「教学参考，须执业医师辨证使用」。
- **本栏目纯只读学习**：未接入处方点评 / 规则引擎判分，不参与推演流程；前端方卡不挂任何规则钩子。
- 与平台既有 46 首用方逐条去重，零重名；重叠原方不重复建条目。

## 二、数据文件与字段口径

- 数据文件：`data/tcm-famous-prescriptions.json`，信封结构 `{ version, note, prescriptions[] }`；`version = 2026.11.24-famous`。
- 字段 schema：

| 字段 | 含义 |
| --- | --- |
| id | 编号：CN-001～CN-040（中方），JP-001～JP-028（日方） |
| name | 方名；aliases 别名（含日本汉字方名） |
| region | `china` / `japan` |
| dynasty_or_period | 朝代 / 时期 |
| author_classic | 作者 / 典籍名 |
| source_ref | 出处文献：书名 + 卷次 / 条文；日本方注明医籍、PMDA 添付文书或一般用汉方承认基准 |
| origin_lineage | 源流：`伤寒金匮原方` / `后世方` / `日本化裁` |
| composition | 组成：`herb` 药味、`role` 君臣佐使、`dose` 剂量、`dose_note` 剂量口径 / 先煎后下等备注 |
| functions | 功用；indications 主治；syndrome_key 辨证要点（舌脉 / 证候抓手） |
| similar_formulas | 类方鉴别；modern_use 现代临床应用范围；cautions 禁忌注意（数组） |
| cn_jp_diff | 中日口径差异；**日本条目必填** |
| references | 参考文献；pinyin 方名拼音（检索用） |

剂量口径：

- 汉魏古方折算采用现代教材常用口径（一两 ≈ 3g），并在备注注明东汉考古衡制另有一两 ≈ 15.625g 一说，两说不混标；枣、姜枚数保留原文并注折算。
- 日本条目为成人一日量（原生药换算 g/日），エキス颗粒通常分 2–3 次食前 / 食间服；标注「承认基准范围」者为基准区间值。

## 四、中日口径差异说明

- **剂量**：日本医疗用 / 一般用汉方原生药换算一日量整体小于中方汤剂常用量；承认基准方多给区间值。中方古方按教材口径折算，考古衡制异说在备注保留。
- **剂型与服法**：日本以医疗用エキス颗粒为主，分 2–3 次食前 / 食间服；中方多为汤剂煎服，部分古方为丸散（如桂枝茯苓丸、失笑散）。
- **适应证范围**：日本条目适应证以添付文书 / 承认基准为准；部分方在日本拓展用于神经症、失眠、更年期障碍、肥胖、皮肤病等，条目在 `modern_use` 与 `cn_jp_diff` 中注明，不与中方传统主治混同。
- **药味差异**：部分日本基准方以苍术代白术（当归芍药散、苓桂术甘汤、六君子汤、抑肝散等）；香砂六君子汤日本以香附代木香并配伍藿香；人参养荣汤中方原方用肉桂 / 桂心，日本基准用桂枝。差异均在组成备注与 `cn_jp_diff` 并列。
- **同名异方**：JP-023（TJ-37，东垣《脾胃论》系统）与 CN-038（《医学心悟》方）为两首同名异方，条目已明确标注，勿混为一方。
- **跨组同名对照**：葛根汤、大柴胡汤、当归芍药散、苓桂术甘汤、猪苓汤、桂枝茯苓丸、桃核承气汤、麻黄附子细辛汤、小建中汤、真武汤、小青龙汤、半夏白术天麻汤 12 首在两组分别从中方典籍视角与日本临床视角收录，组内不重名。
