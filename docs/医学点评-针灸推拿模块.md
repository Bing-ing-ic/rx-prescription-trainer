# 针灸推拿模块医学点评报告

> 评审身份：中医药大学针灸推拿学院副教授 / 针灸科主任中医师
> 评审对象：微光医科大学附属训练平台 · 针灸推拿子模块
> 评审范围：`data/acup-points.json`（97穴）、`data/acup-cases.json`（18案）、`data/acup-rules.json`（28条规则）、`data/tuina.json`（30手法）、`js/acup-engine.js`
> 评审日期：2026-11-06
> 严重度标记：🔴 P0（医学错误/可能误导临床）｜🟡 P1（不准确或不严谨）｜🟢 P2（可优化）

## 一、模块概述

针灸推拿模块由四部分组成：

| 数据 | 规模 | 覆盖 |
|---|---|---|
| 穴位库 | 97 穴 | 十四经常用穴 + 经外奇穴（印堂、太阳、夹脊、十宣、四缝、阿是等） |
| 病例库 | 18 案 | 面瘫、中风后遗症、偏头痛、不寐、眩晕、腰突、颈椎病、肩周炎、坐骨神经痛、三叉神经痛、牙痛、胃脘痛、便秘、泄泻、痛经、荨麻疹、近视、戒烟 |
| 规则库 | 28 条 | FORMAT/PRINCIPLE/PEIPEI/TD/SAFETY 五组 |
| 推拿手法 | 30 项 | 松解/温通/挤压/叩击/运动关节/小儿推拿六大类 |

**总体印象**：模块骨架专业，病例选方多出自《针灸治疗学》规划教材主流处方，安全禁忌（风府、哑门、肩井、神阙、孕妇合谷三阴交）已主动标注，推拿手法分类符合《推拿学》教材体系。作为面向针灸推拿专业本科生和西学中人员的训练工具，**医学正确性主干合格，教学方向正确**。但存在 1 处穴位编码错误、规则与病例不自洽、规则引用库中不存在的穴位等若干硬伤，需要在 P0 级修复后再投入教学使用。

### 2.3 发现的问题

#### 🔴 P0-1 内关 / 间使穴位编码错误

```
PC-06   name: 间使     ← 错误，间使应为 PC-05
PC-06B  name: 内关     ← 错误，内关应为 PC-06
```

心包经标准序：天池PC1、天泉PC2、曲泽PC3、郄门PC4、**间使PC5**、**内关PC6**、大陵PC7、劳宫PC8、中冲PC9。

库中把间使编为 PC-06、内关编为 PC-06B，属于编码错乱。任何按 code 做索引、导出、作业判分的下游逻辑都会错位。**必须修正：间使 → PC-05，内关 → PC-06，并清理 PC-06B 占位。**

#### 🟡 P1-1 交会穴归类文字颠倒

- LI-15 肩髃 `category: "手阳明跷脉交会"` —— 应为"手阳明经与阳跷脉交会"。
- LI-20 迎香 `category: "手阳明阳明交会"` —— 应为"手、足阳明经交会"。
- ST-01 承泣 `category: "足阳明跷脉阳维交会"` —— 应为"足阳明、阳跷、任脉交会"（承泣实为任脉、足阳明、阳跷之会，缺任脉）。

#### 🟡 P1-2 特定穴分类标注不规范

- LI-10 手三里 `category: "手阳明穴"` —— 手三里是大肠经普通经穴，并非特定穴，应直接写"手阳明大肠经穴"或留空。
- SP-10 血海 `category: "脾经穴"`、ST-02 四白 `category: "足阳明穴"` —— 同样的问题，category 字段混用了"经脉归属"和"特定穴类别"两个语义。建议统一：特定穴才填 category（如合穴/络穴/原穴），普通穴填空。

按"十四经郄穴、原穴、络穴、背俞穴、腹募穴、下合穴、八会穴"清单比对，库中缺以下教学高频穴：

## 三、病例选穴逻辑

### 3.1 选方规范性评价

18 个病例的参考处方整体符合《针灸治疗学》（新世纪规划教材）主流方案：

- **ACUP-002 中风后遗症**：内关、水沟、三阴交（醒脑开窍方）+ 极泉、尺泽、委中（阴经松解）+ 手足阳明经穴 —— 这是石学敏院士"醒脑开窍针刺法"的标准结构，选方专业，点评加分项。
- **ACUP-004 不寐**：照海（通阴跷）配申脉（通阳跷）+ 神门、四神聪 —— 完全符合"调理跷脉、安神利眠"治则。
- **ACUP-008 肩痹**：肩髃、肩髎、肩贞（肩三针）+ 臑俞、肩前、条口透承山 —— 标准方案，条口透承山这一经验效穴纳入得当。
- **ACUP-010 三叉神经痛**：第二支取四白、下关、迎香；第三支取颊车、夹承浆；远取合谷、太冲、内庭 —— 按分支配穴，临床思路清晰。
- **ACUP-012 胃脘痛（肝气犯胃）**：中脘、足三里 + 内关、公孙（八脉交会配穴）+ 太冲 + 梁丘（郄穴治急性痛）—— 配穴法齐全。
- **ACUP-015 痛经**：三阴交、中极、次髎、地机、关元、十七椎、太冲 —— 经典寒凝痛经方，地机为脾经郄穴治痛经，选穴精当。

### 3.2 病例问题

#### 🔴 P0-2 规则 ACUP-PRINCIPLE-04 与病例 ACUP-007 不自洽

规则 `ACUP-PRINCIPLE-04 头项寻列缺`：
> "头项强痛、外感头痛、落枕等应配合谷以外的列缺"

但病例 `ACUP-007 项痹（颈椎病）` 的参考穴是：
> 颈夹脊、天柱、风池、大椎、后溪、合谷、外关、曲池

**参考方里没有列缺**，用的是后溪（通督脉治项强）。这本身在临床上是成立的——后溪通督脉、列缺通任脉，均治头项。但规则引擎如果按"头项病必须出现列缺"来判分，就会把一个标准颈椎病处方误判为错误。

**处理建议**：
- 要么在 ACUP-007 参考方中加入列缺（合谷、列缺、后溪三穴同用是临床常见组合，并不冲突）；
- 要么把规则改为"头项病应配合谷、列缺或后溪之一"，与临床多经并取的实际相符。

另外规则文案"应配合谷以外的列缺"语句不通，应改为"应配列缺穴"。

#### 🟡 P1-5 病例难度结构失衡

| 难度 | 数量 | 病例 |
|---|---|---|
| 初级 | 8 | 面瘫、不寐、牙痛、胃脘痛、便秘、泄泻、痛经、近视、戒烟 |
| 中级 | 5 | 偏头痛、眩晕、腰痛、坐骨神经痛、荨麻疹 |
| 高级 | 2 | 中风后遗症、三叉神经痛 |

高级病例偏少，且**缺以下高频教学病种**：
- 感冒 / 咳嗽 / 哮喘（肺系病证，针灸门诊最常见）
- 呕吐 / 呃逆 / 胆石症
- 遗精 / 阳痿 / 遗尿
- 月经不调 / 带下 / 不孕症
- 小儿疳积 / 小儿肌性斜颈（与推拿模块呼应）
- 扭伤（急性腰扭伤、落枕——单穴处方训练）

#### 🟡 P1-6 数据结构不一致

`ACUP-004 不寐` 的 `chief_complaint` 是字符串：
```json
"chief_complaint": "入睡困难、多梦易醒2月，每晚仅睡3-4小时"
```
其他 17 个病例均为字符串数组。前端如果按 `.map()` 渲染会报错或显示异常。应统一为数组。

#### 🟢 P2-2 缺艾灸 / 拔罐 / 皮肤针专项病例

病例 `treatment_method` 字段说明提到"针刺/艾灸/拔罐/推拿/综合"，但 18 个病例参考方案几乎全是针刺，没有一个以灸法为主（如虚寒胃痛灸中脘、隔姜灸治呕吐）、以拔罐为主（如腰背痛走罐）、或以皮肤针为主（如牛皮癣、斑秃）的病例。作为针灸推拿训练平台，治疗手段维度单一。

#### 🟢 P2-3 部分 contraindications 可更临床化

- ACUP-002 中风"血压 >180/110 mmHg 暂缓"——阈值合理 ✅。
- ACUP-005 眩晕血压 165/100，未提示"针灸期间不应停降压药"。建议加一条"不可替代规律降压治疗"。
- ACUP-017 近视未提示"真性近视针灸不能逆转屈光不正，只能改善视疲劳"——这是家长最常见的误解，教学上应当主动声明。

## 四、推拿内容（tuina.json）

### 4.1 总体评价

30 个手法按"松解 / 温通 / 挤压 / 叩击 / 运动关节 / 小儿推拿"分类，符合《推拿学》教材体例。㨰法、一指禅、揉法、摩法、推法、擦法、拿法、按法、扳法、拔伸法的操作要领描述准确：

- TN-01 㨰法："手背近小指部…腕关节屈伸外旋连续往返摆动" ✅
- TN-02 一指禅："沉肩、垂肘、悬腕、掌虚、指实" ✅ 八字诀准确
- TN-06 擦法："不可隔衣操作；可涂润滑剂；以透热为度" ✅
- TN-18 扳法："达到最大限度时再加一个稍增大幅度的短促巧力；弹响后即收" ✅ 安全操作要点
- TN-26/27/28 天河水、三关、六腑：方向、性凉/性温描述正确 ✅
- TN-22~25 小儿外感四大手法（开天门、推坎宫、揉太阳、揉耳后高骨）✅ 组合准确

### 4.2 发现的问题

#### 🟡 P1-7 扳法禁忌症不完整

`TN-18 扳法 contraindications` 已列"颈椎骨折脱位、严重骨质疏松、肿瘤、结核、脊髓型颈椎病、椎动脉型颈椎病慎用"——这一条做得很好。但缺：
- **寰枢关节半脱位**（青少年颈痛常见，盲目扳法可致高位截瘫）
- **椎管狭窄 >50%**、**颈椎不稳**
- **类风湿性关节炎颈椎受累**（寰枢椎半脱位高发）
- **妊娠 3 个月以上腰骶部扳法**

建议补充。

#### 🟡 P1-8 踩跷法适应症偏宽

`TN-21 踩跷法 indications` 含"腰椎间盘突出"。临床踩跷法对**中央型突出、髓核脱出、马尾综合征**是绝对禁忌， contraindications 里虽有"肿瘤结核、骨质疏松、孕妇"，但未明确写"髓核脱出 / 中央型突出 / 马尾综合征禁用"。这条直接关系到医疗安全，建议 P1 补。

#### 🟢 P2-4 缺手法的"补泻方向"标注

- TN-04 摩法已写"顺时针为泻，逆时针为补" ✅
- 但 TN-26~28 小儿推拿的"向上/向下"、"向心/离心"补泻未系统说明。
- 缺"手法强度分级（轻柔/中度/强刺激）"对应适应症的映射表。

#### 🟢 P2-5 推拿与针灸病例未打通

病例库中没有任何一个病例的 `treatment_method` 包含"推拿"，推拿手法库是孤立的。建议至少给 ACUP-007 项痹、ACUP-008 肩痹、ACUP-006 腰痛这三个病证补充推拿方案（㨰法 + 按法 + 扳法 + 拔伸法），形成"针灸 + 推拿"综合处方训练。

## 五、规则引擎与点评规则

### 5.1 规则覆盖度

28 条规则覆盖：
- 格式（FORMAT）：主穴、穴数、刺法注明 ✅
- 选穴原则（PRINCIPLE）：四总穴歌、近部/远部/辨证选穴 ✅
- 配穴法（PEIPEI）：本经、表里、上下、前后（俞募）、左右 ✅
- 特定穴（TD）：五输、原络、俞募、八会、郄穴、下合、八脉交会 ✅
- 安全（SAFETY）：孕妇禁针、风府哑门、肩井、眼周、胸背、神阙、晕针、避血管 ✅

这一框架在同类教学软件中属于**比较完整**的设计。

### 5.2 发现的问题

#### 🔴 P0-3 规则引用了库中不存在的穴位

| 规则 | 引用穴 | 库中是否存在 |
|---|---|---|
| ACUP-TD-02 原络配穴 | 偏历（大肠经络） | ❌ 缺 |
| ACUP-TD-04 八会穴 | 大杼（骨会）、章门（脏会） | ❌ 均缺 |
| ACUP-TD-06 下合穴 | 下巨虚、委阳 | ❌ 均缺 |

学生在前端看到"骨病应取大杼"的点评，但在穴位库里搜不到大杼，会产生认知混乱。**要么补穴，要么改规则文案，二选一。**

#### 🟡 P1-9 引擎 `ACU-MN-01` 主穴匹配门槛过低

```js
const hit = refMain.find(p => names.has(p));
if (!hit) { /* warn */ }
```

只要学生在 7~15 个参考主穴中**任选一个**就算命中。例如 ACUP-001 面瘫参考方有 7 个穴，学生只选"太冲"（远端平肝穴）一个，系统也判定主穴命中。这会放过"只取远端、不取局部"的常见错误。

**建议**：
- 局部主穴（面瘫的阳白、四白、颊车、地仓、翳风）和远端主穴（合谷、太冲）分组，分别要求至少命中 1 个；
- 或者要求命中数 ≥ `refMain.length * 0.5`。

#### 🟡 P1-10 孕妇禁针清单与规则库不完全一致

引擎 `PREGNANCY_FORBIDDEN`：
```js
['合谷','三阴交','昆仑','至阴','肩井','缺盆','天枢','次髎','中极','关元','石门','急脉','血海']
```

而规则 `ACUP-SAFE-01` 文案只写了"合谷、三阴交、昆仑、至阴"。两者不一致。

更重要的是：**血海列入孕妇禁针证据偏弱**。血海治血证、祛风止痒，临床孕妇血海是"慎用"而非"禁针"，古籍也无血海堕胎之说。把血海和合谷、三阴交并列 error 级禁针，属于**扩大禁忌范围**，可能误导学生见孕妇就不敢用血海（而血虚风燥妊娠瘙痒恰恰是血海适应症）。

建议：
- 严格禁针（error）：合谷、三阴交、昆仑、至阴、肩井、缺盆、急脉；
- 慎用（warn）：天枢、次髎、中极、关元、石门、血海、腹部腰骶部强刺激。

#### 🟡 P1-11 缺少以下高频判错规则

- **重复选穴**：同一穴位左右侧重复选取时未提示。
- **虚实补泻矛盾**：寒证/虚证处方全部用泻法，热证全部用补法——引擎只检查"是否标注补泻"，不检查"补泻方向是否与证型一致"。ACUP-005 眩晕参考方特别写了"太冲、侠溪泻；太溪、三阴交补"，这才是正确的补泻同方，引擎应当能识别这种手法分配。
- **禁灸穴误灸**：学生给睛明、承泣、迎香加灸法时未提示。
- **单侧病双侧取穴 / 双侧病单侧取穴**：未提示。
- **同一穴位重复进针深度矛盾**：未检查。

#### 🟢 P2-6 评分权重合理但缺乏"临床思维"维度

当前五维：辨证20 / 主穴30 / 配穴15 / 手法15 / 安全20。
建议加一维"鉴别诊断"（占 10 分），从总权重中扣减，鼓励学生在 `differential` 中主动排除中枢性面瘫、脑出血、肿瘤等，符合真实临床思维。

## 六、教学价值评价

### 6.1 优点

1. **安全意识前置**：风府、哑门、肩井、神阙、孕妇禁针等高危点在穴位库 special_note、规则库 SAFE 组、引擎三处都做了标注，形成三重提示，这是同类软件中少有的严谨。
2. **选方贴近教材**：18 个病例的参考处方与《针灸治疗学》规划教材一致性高，没有自创方。
3. **配穴法完整**：本经、表里、上下、前后、左右、八脉交会、俞募、原络、郄穴、下合穴都有规则覆盖，理论框架完整。
4. **推拿分类规范**：六大类手法分类与《推拿学》一致，小儿外感四大手法、天河水/三关/六腑的补泻属性准确。
5. **病例鉴别诊断齐全**：每个病例都有 `differential` 字段（如面瘫鉴别中枢性面瘫、格林-巴利、中耳炎），这是临床思维训练的亮点。

### 6.2 不足

1. **病种偏外感、痛证、神志病**，缺肺系（咳嗽哮喘）、脾胃慢性（胃下垂、慢性泄泻）、妇科（月经不调、不孕症）、儿科（疳积、肌性斜颈）、皮外（带状疱疹、神经性皮炎）等高频门诊病种。
2. **治疗手段单一**：以针刺为主，灸法、拔罐、皮肤针、耳针、火针、三棱针、电针、温针灸几乎没有出现。
3. **难度梯度偏初级**：8/18 为初级，高级病例只有中风和三叉神经痛，不利于高年级学生能力爬坡。
4. **穴位编码错误（PC-06/PC-06B）**和**规则引用库中无穴**是硬伤，必须先修。

## 八、改进建议（按优先级排序）

### P0 级（建议立即修复，修复前不建议投入教学）

1. **修正心包经编码**：间使 → PC-05，内关 → PC-06，删除 PC-06B 占位。同步检查 `js/acup-app.js` 中所有按 code 引用内关的地方。
2. **统一规则与病例**：
   - 方案 A：在 ACUP-007 项痹参考方中加入"列缺"；
   - 方案 B：把 ACUP-PRINCIPLE-04 改为"头项强痛应配合谷、列缺或后溪"。
   建议选 A，因为合谷、列缺、后溪同用是临床最常见的头项病组合。
3. **补穴或改规则**：在 acup-points.json 中补录大杼 BL-11、章门 LR-13、下巨虚 ST-39、委阳 BL-39、偏历 LI-06 这 5 个穴（至少这 5 个，因为规则直接引用），其他缺失穴可分批补。

### P1 级（建议两周内修复）

4. 统一 category 字段语义：只在特定穴时填写，普通经穴不填。
5. 修正肩髃、迎香、承泣的交会穴描述。
6. 气海 indications 去重。
7. ACUP-004 chief_complaint 改为数组。
8. 孕妇禁针清单分级：
   - error：合谷、三阴交、昆仑、至阴、肩井、缺盆、急脉；
   - warn：天枢、次髎、中极、关元、石门、血海、腹部腰骶强刺激。
9. ACU-MN-01 主穴匹配改为"局部主穴 ≥1 且远端主穴 ≥1"，或要求命中数 ≥ 参考方 50%。
10. 扳法 contraindications 补"寰枢关节半脱位、椎管狭窄>50%、类风湿颈椎受累、妊娠3月以上腰骶"。
11. 踩跷法 contraindications 补"中央型腰椎间盘突出、髓核脱出、马尾综合征"。
12. 补 3~5 个新病例：咳嗽（风寒/风热）、急性腰扭伤（人中/后溪单穴方）、月经不调（血虚）、小儿疳积（四缝+捏脊）、失眠（心脾两虚已有，可加阴虚火旺型）。

### P2 级（建议下一轮迭代）

13. 统一面部禁灸穴标注。
14. 近视病例 special_note 加"真性近视不可逆转"声明。
15. 给腰痛、项痹、肩痹三个病例补推拿综合方案，打通针灸+推拿。
16. 引擎加规则：重复选穴检测、补泻方向与证型匹配检测、禁灸穴误灸检测。
17. 评分维度加"鉴别诊断"10 分，从配穴或手法中匀出。
18. 增加耳穴、皮肤针、三棱针点刺的治疗手段维度。

## 九、结语

针灸推拿模块在**安全禁忌标注**和**教材级处方选方**两方面做得相当扎实，病例鉴别诊断设计是亮点，推拿手法分类规范。作为医学生临床思维训练工具，主干医学方向正确。

但存在 3 个 P0 级硬伤——**心包经穴位编码错位、规则与病例不自洽、规则引用库中无此穴**——这些问题在教学场景下会直接误导学生，必须在投入使用前修复。修复 P0 后，模块整体可达"针灸推拿专业本科 2~3 年级实训可用"水平；完成 P1 后，可作为西学中人员和规培医师的标准化训练工具。
