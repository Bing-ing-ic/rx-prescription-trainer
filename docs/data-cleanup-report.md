## 二、致命医学错误修复（P0）

### 2.1 哮喘急性发作二线静滴错误

| 项目 | 内容 |
|------|------|
| **疾病** | 支气管哮喘急性发作（ASTHMA-J45） |
| **错误** | `second_line_iv` 包含"注射用泮托拉唑钠"（PPI质子泵抑制剂，与哮喘完全无关，疑似从胃溃疡模板复制错误） |
| **修复前** | `['注射用泮托拉唑钠', '地塞米松磷酸钠注射液']` |
| **修复后** | `['氨茶碱注射液', '注射用甲泼尼龙琥珀酸钠', '地塞米松磷酸钠注射液']` |
| **依据** | 哮喘急性发作静脉用药应为支气管扩张剂（氨茶碱）+ 全身糖皮质激素（甲泼尼龙/地塞米松） |
| **新增药品** | 补充了"氨茶碱注射液"条目（0.25g/2ml/支，iv_drip），治疗窗窄需缓慢静滴 |

### 2.2 布地奈德给药途径错误

| 项目 | 内容 |
|------|------|
| **药品** | 布地奈德（普米克） |
| **错误** | `dosage_form` 标为 `iv_drip`（静脉滴注），布地奈德临床只有吸入/鼻喷剂型，**无静脉制剂** |
| **修复前** | dosage_form=iv_drip, pharmacology_class=steroid |
| **修复后** | dosage_form=inhalation（雾化吸入）, pharmacology_class=吸入性糖皮质激素, spec=1mg/2ml/支（雾化混悬液）, is_iv_capable=false |

### 2.3 甘露醇误标为溶媒

| 项目 | 内容 |
|------|------|
| **药品** | 甘露醇注射液 |
| **错误** | `dosage_form=solvent`，被归类为溶媒。甘露醇是脱水剂/渗透性利尿剂，**必须单独快速滴注（30分钟内250ml），严禁作为其他药物的溶媒** |
| **修复前** | dosage_form=solvent, is_solvent缺失 |

## 八、iv_suitability 枚举统一

当前枚举已为标准5级序数结构，无异常值：

```
usually_no_iv < conditional_iv < may_need_iv < needs_iv < iv_preferred
（无需输液）    （条件性输液）    （可能需输液）   （需要输液）  （首选输液）
```

- 急性阑尾炎（APP-K35）：may_need_iv ✓
- 支气管哮喘急性发作（ASTHMA-J45）：may_need_iv ✓
- 糖尿病酮症（KETOSIS-E11）：needs_iv ✓
- 急性胰腺炎（PANCREATITIS-K85）：needs_iv ✓
- 社区获得性肺炎（CAP-J18）：iv_preferred ✓
