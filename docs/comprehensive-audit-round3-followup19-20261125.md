# 防脱乌发名方补录说明（round3-followup19 · 2026-11-25）

## 一、任务背景

用户咨询：中国、香港、日本、韩国是否有防脱发汉方，是否区分性别；随后要求把相关传世名方补录进「汉方学 · 名方鉴赏」库（`data/tcm-famous-prescriptions.json`），**优先收录日本、香港、韩国**，且须为有典籍出处的名方，非经验杂方、单味药或外用民间复方。

## 二、循证结论（补录口径依据）

1. **三地传统医学均无以防脱为主治的本土创制专方**：脱发（斑秃、雄激素性秃发、产后/更年期脱发）在中、日、韩体系中均按辨证选方，同一证型男女可同用，不存在"男性防脱方 / 女性防脱方"的性别专方划分。
2. **性别差异仅体现在病机侧重**：女性多血虚、肝郁、气血不足；男性多湿热、肝肾不足。选方随证，而非按性别固定方药。
3. **香港不单独成方**：香港沿用内地同一中医辨证体系，无独立医学流派与方名体系，故不单独造香港条目；临床所用即下列中医经典方。
4. **日本**：医疗用汉方多为对中医经典方的经验性借用（补血、活血、补气、疏肝、滋补肝肾），缺乏以脱发为终点的高质量 RCT；收入在册医疗用汉方制剂、出处确凿、可辨证用于毛发病证者。
5. **韩国**：本土四象医学无防脱传世成方，韩医临床沿用中医经典方，按四象体质/辨证使用；下列条目在 `cn_jp_diff` 中注明"韩医沿用、非本土创制"。

## 四、工程处理记录

1. **重名规避（校验第 10 项）**：名方鉴赏库 `name` 不得与平台用方库 `tcm-formulas.json`（51 首）重名。四物汤、补中益气汤已在用方库，故海外条目 `name` 采用当地语言写法（日文汉字 / 韩文），简体中文名移入 `aliases` 首位；前端检索同时匹配 `name`、`aliases`、`pinyin`、`functions`，中文名仍可被检索命中。
2. **饮片字典对齐（校验第 9 项 T-3）**：CN-068 君药用字典内"何首乌"，炮制（制用）信息写入 `dose` / `dose_note`，避免新增字典缺口。
3. **出处更正**：二至丸国标 GB/T 31773—2015 载《摄生众妙方》，教材与多份指南引《医方集解》；条目按此两说标注，未沿用不准确的《摄生秘剖》。
4. **剂量口径**：日本条目为医疗用エキス颗粒原生药换算一日量（g/日），备注以添付文书为准；韩国条目按韩医常用量随制剂；中方条目为教材常用量。
5. **香港**：未单建条目；循证口径见第二节，临床用方即上述中医经典方。
