# 医学生处方推演训练平台 · 客观医学点评总报告

> 评审组织：四位医学专家子代理（西医临床药师/内科主治、中医主任/方剂副教授、针灸推拿副教授/主任中医师、解剖学系教授）
> 评审日期：2026-11-06
> 评审方式：静态代码+数据通读（未做浏览器实测）
> 评审对象：`D:\医学生处方推演训练平台\` 全量四模块

---

## 一、总体结论

**平台定位清晰、工程完成度高、中国本土化做得扎实，但医学内容层面存在 20 个 P0 级硬伤，修复前不建议直接用于正式教学。**

| 模块 | 专家评分 | 医学准确性 | 教学价值 | 当前状态 |
|---|---|---|---|---|
| 西医处方（疾病/药品/规则/手术/检验） | **3.7 / 5**（手术库单独 4.5/5） | 中等 | 良好 | 9 个 P0，需大修 |
| 中医汉方（中药/方剂/病例/规则） | **78 / 100** | 中等偏上 | 良好 | 5 个 P0 |
| 针灸推拿（穴位/病例/推拿/规则） | 主干方向正确 | 中等 | 良好 | 3 个 P0 |
| 解剖学（系统/测验/病例/热点/TCM对照） | **8.0 / 10** | 较高 | 良好 | 3 个 P0，可投入使用 |

**一句话判断**：工程骨架（规则引擎、双通道处方、评分反馈、四模块 UI、离线可用）已经达到 MVP 水平；医学内容层（药品剂量、诊断-用药匹配、手术指征、穴位编码、中药毒性安全）还停留在"演示级"，需要一轮系统的数据清洗与医学校对才能真正承担教学训练职责。

## 二、各模块亮点（不吹不黑，这些是真优点）

### 2.1 工程与产品层
- **纯静态离线、双击即用**，无 CDN、无 npm、无构建链，符合基层/教学场景部署。
- **中国本土化到位**：医保甲乙类、国家集采 1–8 批、基药 2026、OTC、抗菌药物分级（non/restricted/special）、门诊输液负面清单、皮试、中药注射剂单独输注、云南本地化数据均已建模。
- **规则引擎+评分反馈**：11 维度百分制、rule_id 级错误定位、雷达图、错题本，教学闭环完整。
- **难度分档**：初/中/高三档，症状池带鉴别性噪声。

### 2.2 西医处方模块
- **手术指征库是全平台最专业的一块（4.5/5）**：Step-up 策略、Early LC、6 小时睾丸扭转窗、FNA→Bethesda 流程、保守 vs 手术时机划分均符合外科学教材。
- 静脉输液专项 9 条规则（IV-01~IV-09）权重 20%，导向正确——针对中国门诊输液滥用的现实痛点。
- 症状池带鉴别性噪声，不直接给"标准答案式"病史。

### 2.3 中医汉方模块
- 约 300 味中药性味归经、用量、十八反十九畏标注 **85% 符合《药典》**。
- 40 首方源选择经典（《伤寒论》《金匮要略》《局方》《温病条辨》），32 首组成功用主治与教材一致。
- 26 例病例辨证→立法→选方对应正确率 85%；**异病同治设计**（头痛/眩晕同用天麻钩藤饮）体现中医思维。
- 难度三级梯度合理，鉴别诊断训练到位。

### 2.4 针灸推拿模块
- 18 个病例选方基本符合《针灸治疗学》规划教材。
- **安全禁忌三重标注**：风府、哑门、肩井、神阙、孕妇合谷三阴交在穴位库、规则库、引擎三处均有警示。
- 推拿六大类手法分类规范。

### 2.5 解剖学模块（评分最高，8.0/10）
- 40+ 高频考点抽查全部符合人卫 9 版教材：翼点/脑膜中动脉、胸骨角、膈三裂孔（T8/T10/T12）、食管三狭窄、Calot 三角、右主支气管、前降支、胸导管、心包裸区、甲状腺手术神经保护、腹股沟疝鉴别、内囊三偏、四边孔腋神经、梨状肌上/下孔、斜角肌间隙、股三角 NAV、臂丛 Erb/Klumpke 瘫、面神经周围性 vs 中枢性瘫、房水循环、垂体窝毗邻、纵隔肿瘤好发部位等。
- **外科解剖把握尤其扎实**：甲状腺/腹股沟疝/腰穿/心包穿刺/乳腺癌腋窝清扫/锁骨下静脉穿刺气胸风险。
- **针灸安全警示专业**：风池向上深刺免伤延髓、云门中府免气胸、人迎避颈动脉。
- TCM 经络-解剖对照（62 个结构映射十四经穴）是差异化亮点。

## 三、P0 级硬伤汇总（共 20 项，修复前不建议投入教学）

### 3.1 西医处方模块（9 项）

| # | 问题 | 正确应为 |
|---|---|---|
| W-1 | `review.js` 权重合计 **120%**（8+23+15+4+20+5+8+10+5+2+5+15=120），百分制模型错误 | 重新归一化到 100% |
| W-2 | **蒙脱石散标注"儿童禁用"**，SPEC-02 会误杀 | 蒙脱石散是儿童腹泻常用药，应改为儿童可用 |
| W-3 | **DKA（KETOSIS-E11）second_line_iv 缺静脉胰岛素**，drugs.json 也没有普通胰岛素条目 | DKA 抢救核心是小剂量胰岛素持续静滴，必须补 |
| W-4 | **哮喘急性发作一线用茶碱缓释片+孟鲁司特** | 应为吸入 SABA（沙丁胺醇）；茶碱是长效维持药、孟鲁司特是控制药，均不能救急 |
| W-5 | APP-K35 first_line_oral 误含静脉药"注射用头孢呋辛钠" | 一线口服不应混入静脉药 |
| W-6 | `disease-lab-map.json` 后半段约 15 个病例的 exam_code 与 `lab-exams.json` 字典**完全对不上**（如 BIO-AMYLASE vs BIO-AMY、BIO-K vs ELE-K、IMG-XRAY-CHEST vs IMG-CHEST-XR），导致 LAB-02 误报率 100% | 全量对齐 exam_code |
| W-7 | 药品双轨命名约 **30 组重复**（"奥美拉唑"vs"奥美拉唑肠溶胶囊"、"左氧氟沙星片"vs"盐酸左氧氟沙星片"），全链路匹配失效 | 统一通用名+剂型，建唯一主表 |
| W-8 | THYROID-E04 手术标准 decision=surgery 但 procedure=FNA_first（FNA 是诊断不是手术），自相矛盾 | 应改 FNA→Bethesda→分层处理 |
| W-9 | LUMB-M51 手术标准直接=surgery，与 teaching_points"80-90% 先保守 3 个月"矛盾，**过度手术导向** | 首诊应保守，手术指征要严格 |

### 3.2 中医汉方模块（5 项）

| # | 问题 | 正确应为 |
|---|---|---|
| T-1 | **朱砂安神丸朱砂 3g 入煎**，超药典 6 倍（《药典》0.1–0.5g，只入丸散不入煎剂），可致汞中毒；病例 TCM-013 同步错误 | 朱砂应入丸散 0.1–0.5g，不入煎 |
| T-2 | **理中丸君药标错**，现标人参为君 | 教材明确干姜为君（温中祛寒），人参为臣 |
| T-3 | 十八反代码 bug：`tcm-engine.js` L15 中 `'北沙参苦参'` 是一个字符串未拆分，导致藜芦配苦参/北沙参无法识别 | 拆为"北沙参""苦参"两个独立药名 |
| T-4 | 药名模糊匹配 bug：`matchAny` 用 `indexOf` 双向包含，"白附子"会被误判为"附子"，触发错误的十八反报警和剂量检查 | 改用精确匹配+剂型后缀分词 |
| T-5 | 外部 31 条规则 JSON 形同虚设：引擎只识别 `type:'herb_pair'`，但规则 JSON 用的是 `trigger/group`，导致**妊娠禁忌、先煎后下、君臣佐使完整、dose_range 逐项检查全部未执行** | 统一 schema，重新接通引擎 |

### 3.3 针灸推拿模块（3 项）

| # | 问题 | 正确应为 |
|---|---|---|
| A-1 | **心包经穴位编码错位**：间使被编为 PC-06、内关被编为 PC-06B | 正确应为间使 PC-05、内关 PC-06 |
| A-2 | 规则与病例不自洽：ACUP-PRINCIPLE-04 要求头项病配列缺，但 ACUP-007 项痹参考方用后溪无列缺，**引擎会把标准颈椎病处方误判错** | 对齐规则与参考方 |

## 四、P1 级问题（本周应修，挑重点列）

### 西医
- 药品剂量只校验"单剂超说明书 1.5 倍"，未做体重/kg 计算（README 已自承）。
- 诊断输入为子串模糊匹配，未做 NLP 纠错。
- 金额恒为 0，未接药品价格表。
- 患者为固定模板，未做既往史/过敏史表单。

### 中医
- 川乌剂量引擎阈值 6g 与规则 3g 矛盾；乌头汤制川乌 6g 超药典。
- 大承气汤君臣佐使标注偏差（芒硝应臣，厚朴枳实应佐）。
- 薏苡仁汤"川乌"未标"制"。
- TCM-010 热积便秘选麻子仁丸偏润，宜大承气汤。
- TCM-FMT-05 示例"瓜蒌皮应写天花粉"医学错误（瓜蒌皮≠天花粉）。
- 妊娠禁忌红花既列禁用又列慎用，自相矛盾（红花桃仁大黄芒硝应归慎用）。

### 针灸
- 孕妇禁针清单把**血海**与合谷三阴交并列 error 级，扩大禁忌（血海孕妇应为慎用）。
- 引擎 ACU-MN-01 主穴匹配门槛过低，15 个参考穴任选 1 个就算命中。
- 扳法禁忌症缺寰枢关节半脱位、椎管狭窄；踩跷法未列中央型腰突/马尾综合征为绝对禁忌。
- 缺大杼、章门、巨阙、日月、京门、偏历、下巨虚、委阳等高频特定穴；病种偏外感痛证，缺咳嗽哮喘、月经不调、小儿疳积。

### 解剖
- 心传导系（窦房结/房室结/His 束/Purkinje）完全缺失。
- 正中神经、尺神经、肌皮神经无独立条目（上肢神经只讲了桡神经）。
- 脊柱韧带（前/后纵韧带、黄韧带、棘间/棘上）无条目。
- 乳腺 Cooper 韧带与淋巴四方向引流缺失。
- 腹膜后隙无整体条目。
- 面神经五大分支、12 对脑神经出颅总表不完整。

## 五、教学价值综合判断

### 5.1 适合什么阶段
- **解剖学模块**：可直接用于低年级医学生（系统解剖学同期）辅助练习，8.0/10 已达可用线。
- **中医汉方/针灸推拿模块**：修复 P0 后适合中医本科 2–3 年级、西医学习中医者作为辨证论治训练工具。
- **西医处方模块**：修复 9 个 P0 后适合本科 4–5 年级见习/规培初期；**当前版本不适合**，因为 DKA、哮喘急救、儿童用药等关键场景会教错。

### 5.2 临床思维训练价值
- **优点**：决策链完整（诊断→检查→处方→手术），规则引擎即时反馈，错题本沉淀能力画像，比纯纸质习题集强。
- **不足**：
  1. 患者画像单薄（无既往史、过敏史表单），真实临床的"合并症决策"训练不到。
  2. 多处方合并点评 UI 未做（DUP-02 跨通道逻辑已实现但前端没流程）。
  3. 缺少"诊断错误"分支——目前病例是给定诊断让学生开方，没有训练"先看错诊断再纠正"的高阶思维。

### 5.3 风险提示
- **医学错误会被学生当权威吸收**：平台带"评分"和"正确答案"外衣，比开放网页更危险。一个 DKA 不补胰岛素、哮喘不推 SABA 的错误，学生记住的概率远大于一份随手搜到的资料。
- 建议在修复 P0 前，在首页加显著声明："本平台为开发演示版本，数据未经医学终审，请勿用于真实临床决策参考"。

## 六、改进路线图

### P0（本周内，阻断性）
1. **修代码 bug 类**（W-1 权重、T-3/T-4 匹配、T-5 schema、N-2 重复字）——工作量小，立即见效。
2. **修医学事实错误类**（W-2 蒙脱石散、W-3 DKA 胰岛素、W-4 哮喘 SABA、T-1 朱砂、T-2 理中丸君药、A-1 心包经编码、N-1 膀胱三角神经）——每条都要有明确医学依据。
3. **修数据对齐类**（W-6 exam_code 映射、W-7 药品唯一主表、A-3 规则引用穴位补库）——需要写脚本批量清洗。

### P1（2–4 周，教学质量）
- 补体重/kg 剂量计算引擎。
- 接通中医 31 条规则的真实执行。
- 补解剖高频考点缺口（心传导系、上肢神经、脊柱韧带、乳腺淋巴）。
- 针灸补特定穴与病种。
- 加患者既往史/过敏史表单。

### P2（1–3 月，产品进阶）
- 多处方合并点评 UI。
- 诊断错误分支训练。
- 接药品价格表与医保实算。
- 旧版 anatomy.json 死数据决策（接通或删除）。
- 浏览器实测：跑 DKA、哮喘、阑尾炎、颈椎病、便秘等 10 个典型病例，验证规则引擎实际输出。

## 七、结语

这是一个**工程意识远高于医学内容成熟度**的平台：作者对教学产品形态（规则引擎、评分反馈、四模块、离线部署）有很好的理解，对中国临床现实（输液滥用、抗菌分级、医保基药）也有准确把握，但医学数据本身还需要一轮真正由临床医生参与的终审。

**修复 20 个 P0 后，这会是一个有特色、可用的医学生训练工具；修复前，它更像一个"看起来像那么回事"的原型，不能让学生真拿它练处方。**
