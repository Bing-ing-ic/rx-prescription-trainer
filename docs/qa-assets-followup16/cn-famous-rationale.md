# followup16「名方品鉴」中国典籍名方 · 编纂说明与存疑清单

> 栏目定位：只读学习内容，不接入处方点评 / 规则引擎判分，不参与推演流程。
> 合规口径：只收有明确典籍 / 文献出处的成方；无可靠出处或剂量依据者不收，列入存疑。
> 通用提示：所有条目均为教学参考，须执业医师辨证使用；毒性药、妊娠禁忌从严标注。
> 剂量口径：汉魏古方折算采用现代教材常用口径（一两 ≈ 3g），并在 `dose_note` 注明东汉考古衡制另有一两 ≈ 15.625g 一说，两说不混标；枣、姜、枣枚数保留原文并注折算。后世方按现代临床常用剂量（g）标注。

## 一、收录总览

- 收录条数：**40 首**（CN-001 ～ CN-040），全部为中国典籍名方。
- 出处分组：伤寒金匮原方 **22** 首；后世方 **18** 首。
- 朝代 / 时期分组：东汉 22、唐 2、宋 5、金 3、元 1、明 1、南宋 1、清 5。
- 药名对齐：composition 内药名全部命中 `data/tcm-herbs.json` 字典名或 `js/tcm-engine.js` 的 `HERB_ALIAS` 别名表；未命中者不写入 composition，列入本说明第三节存疑清单。
- 去重基线：与 SPEC 第二节既有 46 首用方逐条比对，**零重名**。

## 五、数据纪律自检记录

- JSON 可被 `JSON.parse` 解析；UTF-8 无 BOM；2 空格缩进；中文未转义（无 `\uXXXX`）。
- 编号连续：CN-001 ～ CN-040，无断号、无重号。
- 每条 schema 必填字段齐全；composition 内 `herb / role / dose / dose_note` 四项齐全。
- 毒性药标注：附子、细辛、麻黄、罂粟壳、麝香、水蛭 / 虻虫类等在 `cautions` 中从严提示；妊娠禁忌逐条标注。
- 出处、组成、功效主治以人卫《方剂学》教材及典籍原文为准；无可靠依据的剂量、厂家、适应证留空，未臆造。
