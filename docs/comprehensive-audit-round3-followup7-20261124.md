## 3. G2：admin 480 统计芯片溢出收口

- 现状复核：CDP 探针先量得首版复测四宽度卡片 `scrollWidth === clientWidth`、无内部溢出；本轮按既有卡片模式做防御性收口，避免 emoji 字体度量差异在窄宽下再次顶出。
- 改动（`admin.html` 自有 `<style>`，未引入 `rx.css`）：
  - 网格：`repeat(auto-fit,minmax(min(200px,100%),1fr))`——视口小于 200px+间距时不再被最小列宽顶出；
  - 卡片：`min-width:0; overflow:hidden`，内部差值不再外溢；
  - 标签：`flex-wrap:wrap; min-width:0`，文本可换行、零收缩下限放开；
  - `@media (max-width:640px)`：卡片间距 `--space-3`、内边距 `--space-14px`。
- 复测（CDP headless Edge，本地 http 127.0.0.1:8899）：

| 宽度 | 页面级 scrollWidth | 内部溢出元素 |
|---|---|---|
| 480 | 480 | 0 |
| 640 | 640 | 0 |
| 768 | 768 | 0 |
| 1024 | 1024 | 0 |

## 4. G3：class 类规则引擎与弹窗生效复核

- **引擎侧**（`js/rule-engine.js` IV-07 / TCM_EX）：
  - 同一输液组内 ≥2 个 TCM 注射剂 → error；
  - 同一组内 TCM + 其他注射剂（非 TCM iv_drip）→ error（class 类规则，不依赖品种级配对行）；
  - `TCM_EX` 成对扫描显式排除 `scope: 'class'` 占位行，品种级行按通用名双向匹配 `incompatible` / `caution`；
  - 溶媒兜底 IV-06：药品自带 `allowed_solvents_json` 优先，其次 `solvent_drug`，再按 `tcm_injection_rules.solvent_required` 核对。
- **弹窗侧**（`js/app.js` `showDrugDetail`）：TCM 注射剂详情卡读取 `tcm_exclusion` 中 `scope === 'class'` 行的 note 作为"配伍提示"，无 class 行时回退固定提示文案。
- **测试与 smoke**：rule-engine-test IV-07 neg 用例（清开灵 + 维生素C 同瓶）触发 error，套件 80/80 全绿；CDP 打开药品库"参附注射液"详情弹窗，480/1024 均正常展示"配伍提示：中药注射剂严禁与其他药物同瓶混合；须单独成组/单独注射；同一输液通路先后使用须冲管间隔并加强监护。"
- 无新说明书/通报依据的 TCM×化药对维持 class 规则承载，本轮未补品种级行。
