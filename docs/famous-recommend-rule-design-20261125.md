# 名方鉴赏 ·「按症寻方」规则版改造方案（设计规格 · 中日双轨结合）

> 版本：2026-11-25（v2）　｜　模块：汉方学 · 名方鉴赏　｜　路线：纯前端规则 + 检索自动匹配（本期不接大模型）
> 适用仓库：`rx-prescription-trainer`　｜　现状基线：名方库 121 首（中国 69 / 日本 44 / 韩国 8）
> 方法论定位：**中医辨证论治为主线，吸收日本汉方「方证相对 + 结构化适应证」的严谨做法，双轨结合推荐**

---

## 1. 背景与目标

### 1.1 现状
- 名方鉴赏现为只读学习栏目，模态框 `modal-famous-lib`，提供「关键词 + 地区 + 典籍」三级浏览检索；检索逻辑为名称/别名/拼音/功用文本包含匹配，**无证候-症状结构化匹配能力**。
- 现有规则引擎 `tcm-engine.js` 面向病例点评判分（辨证→治法→选方对照参考方打分），**不是从症状反推方剂的检索引擎**，二者职责不混用。
- 平台为纯静态站（GitHub Pages），数据全部本地 JSON，无后端、无大模型接口。

### 1.2 本期目标
在名方鉴赏内新增「按症寻方（辨证选方）」面板：学生通过**选证候 / 点选症状 / 手工输入**三种方式给出线索，系统经规则匹配推荐名方，并给出可解释的命中理由、类方鉴别与禁忌提示。

### 1.3 教学定位（不可突破的红线）
1. **先辨证、后选方**：系统不允许从症状一步跳到方剂。先由症状归纳候选证型，学生确认辨证后，再出推荐方。
2. **只读学习，不判分、不入推演**：延续现有免责口径——不接入处方点评与规则引擎判分，不参与处方推演流程。
3. **推荐只来自本地名方库**：前端不生成库外方名、药味、出处；所有结论可回溯到库内条目字段。
4. **教学参考，非诊疗依据**：固定免责声明；不输出剂量决策；毒性/禁忌药味在详情中警示。

## 2. 两种医学模式辨析与取舍（为什么是结合，而不是纯日本模式）

### 2.1 中医辨证论治模式
四诊合参 → 辨证（八纲 / 气血津液 / 脏腑 / 六经 / 卫气营血）→ 立法 → 选方。长于**病机推演与脏腑气血津液分析**，个体化强；证型是独立于方剂的抽象辨证结论。

### 2.2 日本汉方「方证相对」模式
- 核心为**方証相対（ほうしょうそうたい）**：「証（しょう）」常以方名命名（如葛根湯証、大建中湯証），诊断与选方近乎同一行为——患者的特征症状群 / 所见与某方的方证一致即选方，即「同病异治、异病同治」。
- 辨证参照框架：**八纲**（表里 / 寒热 / 虚实）、**気血水**（気虚・気滞・気逆 / 血虚・瘀血 / 水滞）、**六病位**（六经）、**腹证（腹診）**、脉舌。
- 严谨性体现：医疗用汉方制剂处方固定，添付文书以「体力（虚/中等/壮）+ 体质倾向 + 目标症状群 + 次の諸症（适应证）+ 禁忌」文书化记载；腹证等客观体征直接指向具体方剂。

### 2.3 为何不采用纯日本模式
1. **教学对象与目标**：本平台面向中国医学生，训练对接中医辨证论治；纯方证相对跳过脏腑病机推演，不符合课程目标。
2. **库内结构**：121 首中中方 69 首，多数未记载腹证；纯腹证 / 体质框架覆盖不全。
3. **载体限制**：静态站无法实施腹诊触诊操作，腹证只能作为典籍记载的文字指征展示，不能作为主要诊断手段。

### 2.4 结合方式（本方案采用）
- **主线保留中医辨证两步走**：辨证 → 立法 → 选方，完成病机训练。
- **吸收日本汉方的结构化长处**：
  - 为每首方抽取**目标症状群（方证所见）**，做「症状群 → 方」的直接、可核对对应；
  - 增补**虚实 / 気血水 / 六病位 / 腹证**标签维度，作为辅助匹配与知识展示；
  - 详情与结果卡片采用**添付文书式结构化分区**（体力体质、目标症状群、腹证所见、适应证、禁忌）；
  - 日韩条目优先标注日本方证视角，中方条目以中医证型为主、日本维度缺省留空。
- **严谨性中立说明**：日本汉方的严谨主要体现在制剂标准化与适应证文书化；中医长于病机辨证。二者严谨维度不同，方案不抬高一方，标签缺省不强行套用。

## 3. 专家视角与评审清单

本方案由三条专业视角共同把关，落地与验收时逐项核对。

### 3.1 中医方剂学 / 辨证严谨性视角
- 证型、症状、脏腑、治法标签是否采用规范术语，分组符合辨证论治逻辑（八纲 / 气血津液 / 脏腑 / 六经 / 卫气营血）。
- 辨证两步顺序是否符合「四诊合参 → 辨证 → 立法 → 选方」的临床思维。
- 类方鉴别、禁忌注意、出处文献是否与库内既有字段一致，不出现误导性推荐。
- 低证据场景是否明确提示依据不足，而非硬推。

### 3.2 日本汉方方证视角
- 方证相对对应是否准确：目标症状群是否为该方典籍 / 添付文书所载特征所见。
- 虚实、気血水、六病位归类是否规范；腹证记载是否有据（无记载不补造）。
- 日本方证名（××湯証）使用是否恰当；与中医证型表述是否冲突或可并存。
- 日韩条目与中方条目的日本维度标注口径是否一致。

### 3.3 前端交互 / 视觉设计视角
- 带入感：临床推演情境引导，弱化工具感；信息层级清晰。
- 趣味性：即时反馈、辨证挑战、已学进度等轻激励，不干扰学习主线。
- 知识性：标签可释义、出处可追溯、鉴别可对照。
- 可用性：键盘可达、焦点可见、aria 标注、窄屏响应式、与现有医疗蓝设计语言一致。

## 4. 数据模型扩展

### 4.1 名方库条目增补可选字段
现有 18 个字段（`id, name, aliases, region, dynasty_or_period, author_classic, source_ref, origin_lineage, composition, functions, indications, syndrome_key, similar_formulas, modern_use, cautions, cn_jp_diff, references, pinyin`）**全部保留不动**。新增以下可选字段，缺省时由原有文本字段兜底参与匹配，不破坏既有校验。

**字段约定**
- `tags.*` 取值必须命中受控词表（见 4.2）；未收录的新词先入词表再打标，避免自由漂移。

- `fukushin`、`six_channel`、`ki_ketsu_sui` 等日本维度在中方条目可缺省；无典籍依据不得补造。
- `difficulty` 用于教学分层展示，不参与硬性过滤。

## 5. 匹配与打分规则（规则版，纯前端可解释）

### 5.1 输入归一流程
1. 文本 `trim`、转小写、去标点；拆分 token。
2. 每个 token 依次尝试：症状词表 → 证型词表 → 日本维度词表（虚实/気血水/六病位/腹证）→ 治法/脏腑词表 → 自由关键词。命中即归一到标准词。
3. 拼音首字母输入走 `pinyinMatch` 兜底。
4. 已选标签（下拉/点选）直接作为标准词进入集合；手输文本经上述归一后并入。

### 5.2 双轨打分模型
每条候选方分别计算 **A 轨（中医辨证）** 与 **B 轨（日本方证）** 轨内得分（各满分 100），再按地区权重折算综合分（0–100）。

**A 轨 · 中医辨证轨（轨内满分 100）**

| 维度 | 轨内权重 | 计分规则 |
| --- | --- | --- |
| 证型契合 | 45 | 确认证型与 `tags.syndromes` 精确命中满分；近义词/包含命中按 60%；未命中 0 |
| 脏腑契合 | 20 | `tags.organs` 命中累加 |
| 治法契合 | 35 | `tags.treatments` 命中累加 |

**B 轨 · 日本方证轨（轨内满分 100）**

| 维度 | 轨内权重 | 计分规则 |
| --- | --- | --- |
| 目标症状群 | 45 | 每命中一个 `tags.target_symptoms` 累加，主症权重高于兼症 |
| 気血水契合 | 20 | `tags.ki_ketsu_sui` 命中累加 |
| 虚实体质 | 15 | `tags.kyo_jitsu` 命中 |
| 腹证 / 舌脉 | 20 | `tags.fukushin / tongue / pulse` 命中累加 |

**综合分折算（wA + wB = 1）**

| 条目地区 | A 轨权重 wA | B 轨权重 wB | 说明 |
| --- | --- | --- | --- |
| china | 0.65 | 0.35 | 以中医证型为主，日本维度为辅 |
| japan / korea | 0.40 | 0.60 | 以方证症状群 / 体质气血水为主 |

- **文本兜底校准（附加 ≤10 分）**：结构化标签缺失时，在 `indications / syndrome_key / functions` 文本中包含关键词，按命中数给分，防止新打标条目全丢分；兜底分不计入双轨权重。
- 地区、典籍作为**前置过滤**（沿用现有下拉），不计入打分。
- 同分排序优先级：综合分 > A 轨证型命中 > B 轨目标症状群命中 > 库内条目层级（中方经方优先）。

### 5.3 阈值与展示分级
- 结果按综合分降序，展示 Top 6。
- **≥ 60 分**：标记「推荐」（蓝绿）；**40–59 分**：标记「可参考」（琥珀）；**< 40 分**：不进入推荐列表，或置灰并提示依据不足。
- 命中理由自动生成，双视角呈现，示例：
  > 中医辨证：肝肾不足证；命中主症：须发早白、腰酸膝软；治法：补益肝肾、填精补血。
  > 方证视角：虚証・血虚倾向，目标症状见须发早白、齿摇发落；类方鉴别：二至丸、六味地黄丸。

### 5.4 两步辨证流程（防跳步）
**第一步 · 归纳证型**：学生输入症状/文本后，系统按症状集合反推候选证型（对 `syndromes` 与 B 轨目标症状群综合打分），列出 2–4 个候选证型卡片，每张附一句病机抓手；学生点选其一，或手输证型。
**第二步 · 确认后出方**：证型确认后解锁结果区，按 5.2 双轨打分推荐。

- 若学生跳过辨证直接浏览结果：允许查看，但结果区标注「未完成辨证，结果仅供浏览」，并将证型维度权重降权。
- 辨证反馈（呼应现有 `checkZheng` 样式）：学生所选证型与推荐方所主证型契合时显示 ✅「对证」；偏差时显示 🤔「可再斟酌」，并提示结合舌脉重新判断。

### 5.5 兜底与空态
- 无命中：引导补充信息维度（舌象、脉象、腹诊所见、病程、二便、月经带下、情志睡眠等），不硬推。
- 词表未覆盖的口语：走文本兜底；仍无命中则进入空态文案。
- 任何低分/证据不足场景，均提示「对证依据不足，建议四诊合参、结合面诊」。

## 7. 视觉带入感与趣味性 / 知识性设计

### 7.1 视觉规范（复用现有设计变量）
- 主色沿用医疗蓝体系：`--blue-deep #0f4c81` / `--blue-mid #1a6fb5` / `--blue-light #2c7be5`；汉方模块沿用 `tcm-hero` 专属调性。
- 圆角：小 4 / 中 8 / 大 16（`--radius-sm/md/lg`）；过渡 `--ease` / `--dur`。
- 背景：浅色宣纸/古籍质感底纹（低透明度，不影响可读性）；卡片留白、柔和阴影。
- 卡片交互：悬浮抬升 + 柔和阴影 + 过渡；选中态内发光描边。
- 匹配度配色：推荐=蓝绿，可参考=琥珀；低分区置灰。
- 标签分色编码：证型 / 症状 / 治法 / 脏腑 / 気血水 / 腹证各一色，附图例说明。
- 图标：沿用现有线性 emoji 风格（☯ 🌿 📖 🔍 🩺）。

### 7.2 趣味性 / 轻激励
- **辨证挑战**：先不看推荐，从候选证型中自行判断；确认后系统对比所选证型与方条所主证型，即时反馈对证与否。
- **已学进度**：本地 localStorage 记录「已学名方」与本次浏览计数，key 带 `module: 'tcm-famous'` 字段（复用现有 localStorage 习惯）。
- **类方鉴别小测**：结果/详情侧栏给出 2 首相似方的一句话区别，点击展开对照。

### 7.3 知识性
- 标签悬停释义：症状/证型/気血水/腹证标签附 `hint` 一句话病机解释。
- 出处可追溯：卡片与详情保留典籍、朝代、作者/出处文献、参考文献。
- 源流差异：日韩条目保留 `cn_jp_diff` 中外口径说明；日本方证名与中医证型并陈，便于对照学习。

## 8. 严谨性与合规保障

## 附 A：样例推演（防脱乌发类 · 双视角）

**输入**：症状点选「须发早白、腰酸膝软」，手输「头发掉、肝肾不足」。
**归一**：症状→`毛发干枯脱落/脱发齿摇/腰酸膝软`；证型→`肝肾不足证`；B 轨倾向→血虚、虚証。
**第一步辨证**：候选证型「肝肾不足证」「精血亏虚证」，附病机抓手；学生确认「肝肾不足证」。
**第二步推荐**：
- 七宝美髯丹（推荐）——中医：补益肝肾、填精补血；方证：虚証・血虚，目标症状须发早白、齿摇发落；类方：二至丸、六味地黄丸。

- 六味地黄汤（可参考）——滋补肝肾；命中腰酸耳鸣、须发早白。
**兜底提示**：若未补充舌象、脉象、病程，标注「辨证依据有限，建议四诊合参」。
