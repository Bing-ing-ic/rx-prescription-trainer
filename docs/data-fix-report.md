## 一、拼音首字母补全（drugs.json）

### 结论
- 药品总数：**322**。
- 修复前：仅 32 个有 `pinyin_code`（大写），84 个有小写 `pinyin`，**206 个完全没有拼音字段**。
- 修复后：**322/322 全部同时拥有 `pinyin`（小写）与 `pinyin_code`（大写）**。
- 新补 `pinyin_code`：**290** 个；新补小写 `pinyin`：**238** 个。

### 为什么同时补了 `pinyin`
运行时 `js/app.js` 第 77 行的搜索逻辑是：

```js
const py = DRUG_PINYIN[d.generic_name] || d.pinyin || '';
if (py.indexOf(kw) >= 0) return true;
```

它实际读取的是 `d.pinyin`（小写），**并不读取 `pinyin_code`**。只补 `pinyin_code` 并不能让前端搜索生效，因此本次为每个药品同时写入成对的 `pinyin`（小写，供运行时搜索）与 `pinyin_code`（大写，数据规范字段），二者值互为大小写。

### 取码规则
参照库内已有风格（`DRUG_PINYIN`、84 条数据内 `pinyin`、32 条 `pinyin_code` 一致采用「通用名逐字拼音首字母、保留剂型后缀字」）：
- 每个汉字取拼音首字母；
- 保留名称中的字母/数字（如 `维生素B6`→`wssb6`、`维生素K1`→`wssk1`、`α-2b`→`2b`）；
- 去掉前置浓度前缀 `0.9% / 5% / 10%`（如 `0.9%氯化钠注射液`→`lhnzsy`）；
- 去掉末尾罗马数字 `III/Ⅲ`（如 `口服补液盐`→`kfbyy`）；
- 异读字按医学术语发音纠正（如 `重组人干扰素` 的「重」读 chóng → `c`，不作 `z`）。

### 关于原 84 条小写 `pinyin`
原始 84 条小写拼音存在系统性错误甚至夹带空格，直接大写会损坏搜索，例如：

| 药品 | 原 pinyin | 问题 | 修正后 |
|---|---|---|---|
| 氯化钾注射液 | `hlhsdsy` | 首字母全错 | `lhjzsy` |
| 雷尼替丁胶囊 | `lntdj n` | 含空格 | `lntdjn` |
| 枸橼酸铋钾颗粒 | `jysbjk kl` | 含空格 | `jysbjkl` |
| 乳果糖口服液 | `rg tg kf` | 含空格、错位 | `rgtkfy` |
| 阿司匹林肠溶片 | `aspclp` | `asplcrp` 漏字母 | `asplcrp` |
| 氯吡格雷片 | `blglp` | 氯应为 l，误作 b | `lpglp` |

因此这 84 条未简单「大写照抄」，而是按准确拼音重算（同时满足任务「拼音首字母必须准确」的硬性要求）。
